# 数学知识星图 Math Starmap

**在线打开：<https://xhc144.github.io/claude-lab/math-starmap/>**

以清华大学 2027 新领军计划考试大纲（数学与物理）为纲的知识宇宙。每个定义、定理、方法、例子与应用都是一颗星；前置、推导、推广、等价、应用、例子等关系把它们连成星座。整张星图可以自由缩放、拖动，点开一颗星就能沿着关系不断展开下去。全部知识写在本仓库的 Markdown 文件里，运行时不调用任何 AI 接口。

## 怎样用

- **星图**：七个星系按主题排布，高中数学居中。滚轮或双指缩放、拖动平移；远看是星系与星团，近看出现每颗星的名字。线的颜色与线型区分关系：蓝色实线前置、金色实线推导、紫色虚线推广、绿色双线等价、橙色点线应用、粉色短划线例子、灰色点线相关。
- **知识卡片**：单击一颗星打开。内容按“陈述 / 直观 / 证明 / 例题 / 应用 / 注记”分节，证明默认折叠；正文里的蓝色链接可以直接跳到别的星。卡片里可以标记“学习中 / 已掌握”、收藏，查看全部关系。
- **星链**：双击一颗星（或按 E）进入。它从这颗星出发长出一张局部关系网，点击邻居继续展开，没有尽头；选中的星周围的“卫星”直达卡片里的内容、证明、例题与动画。
- **学习路径**：选一颗目标星，列出学会它所需的全部前置知识并排成可以依次学习的顺序（大学内容不会成为高中知识点的前置）。可以跳过已掌握的星，按顺序飞过去。
- **知识航线**：任选两颗星，找出连接它们的最短关系链。
- **搜索**：标题、别名、英文名、拼音全拼与首字母（如 `taile`、`tlgs` 找到泰勒公式）、标签、摘要与正文。按 `/` 聚焦。
- **进度与收藏**：保存在本机浏览器的 localStorage 中，不上传。
- 快捷键：`/` 搜索 · `E` 星链 · `0` 全景 · `R` 随机一颗星 · `F` 收藏 · `M` 标记已掌握 · `Esc` 返回 · `?` 帮助。

## 本地运行

需要 Node.js 18 以上，网站本身没有运行时依赖。

```bash
npm start            # 构建（内容问题只警告）并在 http://localhost:5173 打开
npm run build        # 严格构建到 dist/，并重新生成 COVERAGE.md
npm test             # 单元测试 + Playwright 端到端测试（先 npm ci）
npm run pinyin       # 修改标题或别名后重新生成 data/pinyin.json（需要 npm ci）
```

构建会检查：id 唯一、关系指向存在的星、前置与推导关系不成环、每个公式都能被 KaTeX 排版、考纲每个列项都被覆盖、引用的动画存在。

## 扩充知识库

知识都在 [content/](content/) 里：一个 Markdown 文件是一个星团，`## 标题 {#id}` 开始一颗星，下面几行写类型、前置、推导、推广等关系，正文支持 `$…$` 公式、`[[id|文字]]` 链接与 `> [!定理]` 提示框。完整格式见 [content/README.md](content/README.md)。改完运行 `npm start` 即可看到新的星。

## 目录

```text
content/          知识库（Markdown）、考纲列项、精选航线
scripts/          构建（解析、校验、布局、打包）、本地服务器、拼音表生成
src/core/         图数据、路径算法、搜索、本地存储、公式排版
src/view/         画布渲染：星空、星图、星链、相机与输入
src/ui/           卡片、侧栏、顶栏、航线播放、开场与帮助
src/anim/         37 个交互动画与它们共用的绘图工具
tests/            单元测试（node --test）与端到端测试（Playwright）
vendor/katex/     KaTeX 0.16.22（MIT 许可，只保留 woff2 字体）
```

星的位置由确定性的力导向布局在构建时算出（同样的内容总得到同样的星图），缓存在 `.cache/`。
