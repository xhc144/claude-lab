关于这些项目

每个实验一个目录，各自保留依赖、构建脚本与 Git 历史。网页版本是预先构建好的静态文件；影片播放的是已生成的 H.264 / AAC 成片。

数据与隐私

游戏与沙盒存档只保存在你自己的浏览器里，清理浏览器数据前请先导出。星枢 Tensora 的模型、厂商与账单全部为虚构；本站不包含任何凭据、安装包或用户数据。

在本地构建

在仓库根目录运行 node scripts/build-pages.mjs 重建全部站点产物；只改了导航时运行 node scripts/build-site.mjs。
