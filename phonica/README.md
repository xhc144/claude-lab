# 声准 Phonica · 英语口语训练与发音评测

Windows 桌面软件：朗读单词、句子或文章，在本机完成**音素级**发音评测（准确度、完整度、流利度、语速、停顿、重音、语调），给出带时间位置的单词/音素纠错、波形 / 音高 / 语谱 / 元音图，以及英音、美音标准发音。AI 深度分析是可选的附加功能；不配置任何 AI 接口时，录音、评测、历史与导出都完整可用。

**下载：** [Releases → 声准 Phonica（Windows 安装包）](https://github.com/xhc144/claude-lab/releases)，运行 `Phonica-Setup-<版本>-x64.exe` 安装（无需管理员权限，可选安装目录）。所有模型随安装包离线提供，评测不需要联网。从 1.1.0 起，装好的软件会自己检查并安装新版本（设置 → 软件更新，可以关掉）；更新只连接本仓库的 GitHub 发布页。签名与更新的做法见 [scripts/windows-release/](../scripts/windows-release/README.md)。

## 功能

| 模块 | 内容 |
| --- | --- |
| 朗读与录音 | 粘贴任意英文 / 导入 txt、md、docx、字幕；单词、句子、文章三种模式；文章可逐句练习；录音可暂停、继续、放弃；静音自动停止；跟读模式（播放标准发音后自动录音）；快捷键 空格 录音、P 播放标准发音 |
| 传统发音评测（核心） | 总分、准确度、流利度、完整度、韵律；单词重音正确率、句尾语调正确率；逐词、逐音素 0–100 分；替换 / 漏读 / 不准确 / 词尾加音等错误类型，“听起来像 /s/” 的实际读音，中文纠正方法；语速（词/分、音节/秒、去停顿发音速度）、停顿位置与类型、填充声、平均语流长度；音高范围、单调检测、nPVI 节奏、实词与虚词突显差 |
| 可视化 | 波形 + 音高曲线 + 能量 + 单词 / 音素分层时间轴（点击即播放、可缩放），可叠加标准发音的语调曲线逐词对比；语谱图（含元音共振峰标记）；元音共振峰图（与美式英语参考值对照） |
| 标准发音 | 离线神经语音合成（Kokoro），美音 4 个、英音 4 个发音人，0.5–1.5× 语速；英音 RP 与美音两套音标；单词级标准发音与慢速；句中标准读法逐词回放；我的录音 0.6–1.25× 变速（音高不变）、循环 |
| 历史与进步 | 每次练习的录音（无损 WAV）与完整结果保存在本地；进步趋势图；任意两次练习的总分 / 各项 / 逐词对比；同一内容多次尝试的即时对比；收藏 |
| 薄弱项与专项练习 | 自动统计所有练习中各音素的错误率与常错单词；每个音素有发音要领、练习词、练习句与对应最小对立词；一键生成专项练习 |
| 素材库 | 16 组最小对立词（针对中国学习者常见混淆）、单词重音、日常句子、语调、绕口令、公版短文；可新建与导入自己的素材 |
| AI 深度分析（可选） | OpenAI、Claude、DeepSeek、Gemini 与任意 OpenAI 兼容接口（含本地模型 / 中转）；自定义地址、密钥、模型；能接收音频的模型同时收到压缩录音与评测数据，不能接收音频的模型只收到评测数据，结果分别标注“已直接听取录音”或“仅基于传统评测数据”；流式输出、可停止、历史保存；密钥用 Windows DPAPI 加密保存 |
| 导出（不需要 AI） | 一键 ZIP：高压缩录音 `recording.mp3`（默认 64 kbps / 24 kHz 单声道）、`report.md` 可读报告、`analysis.json` 完整结构化数据（单词 / 音素时间戳、评分、错误、语速、停顿、重音、语调、共振峰、音高与能量曲线）、`prompt.md` 自动生成的分析提示词、原文；也可单独导出音频、报告、JSON 或提示词；显示预计大小与实际大小，提供 32–192 kbps 多档音质；可附带标准发音音频 |

## 评测原理

```
录音 (WAV, 原始采样率) ──► 16 kHz
文本 ──► 分词 / 数字与缩写展开 ──► 发音词典 (CMUdict 全部变体 + eSpeak-NG 英式 RP + 神经网络 G2P)
                                         │ 美式 / 英式变体，口音不同不算错
  ├─ charsiu en_w2v2_fc_10ms：10 毫秒帧级音素后验
  │     └─ Viterbi 强制对齐（可选静音、填充 / 多读吸收、漏读跳过）→ 单词与音素时间边界
  │           └─ 帧级 GOP：LPP、LPR、帧一致率、竞争音素、时长
  ├─ wav2vec2-lv-60-espeak-cv-ft：CTC 音素识别
  │     └─ 无需对齐的 CTC GOP：目标音素串 vs 每个音素被替换为其他英语音素或删除后的最佳音素串
  │        → “实际读成了什么” 与漏读证据
  ├─ YIN 基频、能量、LPC 共振峰 → 重音（响度 + 音高 + 时长）、句尾语调、节奏
  └─ 校准回归：音素 MLP → 单词 MLP → 句子级准确度 / 流利度 / 韵律 / 总分
```

评分模型在 [speechocean762](https://github.com/jimbozhang/speechocean762)（5000 句中国学习者英语朗读，5 位专家标注，CC BY 4.0）**训练集**上训练，在**独立测试集**（不同说话人）上验证。与专家评分的皮尔逊相关系数：

| 层级 | 本软件（测试集） | 参考：GOPT (Gong et al., 2022) |
| --- | --- | --- |
| 音素准确度 | **0.595** | 0.612 |
| 单词准确度 | **0.578** | 0.533 |
| 句子准确度 | **0.723** | 0.714 |
| 句子流利度 | **0.744** | 0.753 |
| 句子韵律 | **0.738** | 0.760 |
| 句子总分 | **0.730** | 0.743 |

整体与 GOPT 相当：单词与句子准确度略高，音素、流利度、韵律与总分略低。GOPT 是论文中的研究模型；本软件的模型全部是可在普通 Windows 电脑 CPU 上离线运行的 INT8 量化模型（一句话评测通常在 1 秒左右完成）。

音素错误判定阈值在训练集留出说话人上选取。在测试集上：<60 分（“错误”）标记约 3.7% 的音素，其中 61% 被专家判为读错或明显不准，覆盖约三分之一的专家错误；<80 分（“错误”+“欠准”）标记约 11% 的音素，覆盖约 62% 的专家错误。所有模型选择（MLP 还是岭回归、隐藏层大小、阈值）只用训练集数据（按说话人留出或分组交叉验证）决定，测试集只用于报告上表。

**典型替换音的额外判定。** speechocean762 的专家对中国学习者最常见的辅音替换相当宽容（例如把 “then” 读成 /zɛn/ 往往仍给满分），只按专家评分校准会让这些错误“隐身”。因此在校准分数之外加了一条公开规则（`src/engine/substitution.ts`）：对 /θ/→/s f t/、/ð/→/z d/、/v/→/w b/、/w/→/v/、/r/→/l w/、/l/↔/n/、/ŋ/↔/n/、/ʃ/↔/s/、/tʃ/→/ʃ/ 这类音位性替换，当帧级模型与 CTC 识别模型都听成同一个音，或 CTC 识别模型以很大差距听成该音时，标为替换，并把该音素和所在单词的分数限制在 79 以下（“一般”档，界面高亮）；“in London”“is the”“and the” 等连读同化不计。上表已包含这条规则的影响（音素相关系数 0.598 → 0.595，单词 0.586 → 0.578）。在 48 句英音 / 美音合成标准朗读（1427 个音素）上这条规则没有产生误报（整套评测在其中共标出 1 个音素）；在人为替换音素后合成的录音上，/ʃ/→/s/ 检出 100%，/n/→/l/ 83%，/r/→/l/ 71%，/v/→/w/ 45%，/θ/→/s/ 36%，/ð/→/z/ 20%。后几项检出率偏低，是因为两个声学模型都会受单词上下文影响把 /θ/、/ð/ “听回”标准音；音素详情中仍会显示最接近的竞争音。

完整度直接按检测到的单词比例计算。重音、语调、节奏、停顿与语速是直接测量的结果；其中单词重音判定（响度、音高、时长的加权突显度，另一音节需明显更突出才判错）的参数用 speechocean762 训练集的单词重音标注选取：测试集上约 9% 的正确重音单词被误判、约 34% 的错误重音被检出，在 56 句合成标准朗读中误判率约 1%，因此界面把它表述为“可能”重音不对。共振峰由 LPC 估计，仅供参考。

已知局限：评分基于中国学习者的专家标注，对母语者或其他母语背景的学习者可能有偏差；上下文很强的句子中，个别替换音可能被模型“自动纠正”而漏判（音素详情中仍会显示两个模型各自的证据）；背景噪声、混响和过载录音会降低可靠性。

## 隐私

录音、评测结果、AI 分析和素材默认保存在 `文档\Phonica`（可在设置中更改），评测全部在本机进行。只有在你点击“开始分析”时，才会把压缩录音（仅限能接收音频的模型）和评测数据发送给你配置的 AI 服务。ONNX Runtime 的使用统计已通过 `ORT_DISABLE_TELEMETRY` 关闭。

## 开发

```sh
cd phonica
npm ci                     # 需要 Node 22
npm run fetch-models       # 下载并校验模型（约 565 MB）到 models/
npm test                   # 单元测试 + 引擎测试
npm run dev                # 构建并启动
npm run dist:win           # 生成 Windows 安装包（在 Windows 上运行）
```

- `src/engine/`：评测引擎（纯 TypeScript + onnxruntime-node），也可用 `tools/assess-cli.ts` 在命令行运行
- `src/main/`：Electron 主进程、评测引擎子进程（utilityProcess）、本地存储、导出、AI 服务
- `src/renderer/`：React 界面；`src/shared/`：类型、报告与提示词、练习素材
- `tools/dump-so762.ts` → `tools/features-so762.ts` → `tools/calibrate.py`：在 speechocean762 上提取特征、训练并评估评分模型，输出 `resources/scoring/scoring.json`
- `tools/models/export_models.py` 与 `.github/workflows/phonica-models.yml`：把 Hugging Face 上的 wav2vec2 模型导出为 ONNX（fp32 / INT8），逐一与 PyTorch 输出比对后发布到 `phonica-models-v1`
- `.github/workflows/phonica-windows.yml`：在 Windows 上测试、打包 NSIS 安装包，静默安装后运行内置自检（`Phonica.exe --self-test out.json`：加载模型、评测正确与故意读错的录音、语音合成、MP3/ZIP 导出、界面截图）；提交信息含 `[release]` 或手动运行时发布 Release，并刷新 `phonica-latest` 里的自动更新信息
