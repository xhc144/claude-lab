# 数境 MathScape — 交互式数学可视化

在浏览器里实时计算、实时绘制的数学可视化软件。打开后先看到**开启页面**（四个模块的实时预览、精选示例与精度设置），再进入四个模块：

| 模块 | 内容 |
| --- | --- |
| **矩阵线性变换** | 2×2 矩阵作为平面变换：拖动基向量改矩阵；网格变形动画（线性 / 极分解 / 指数 Aᵗ / SVD 分步四种路径）；行列式面积、特征方向、奇异值椭圆、Aⁿv 迭代轨道与连续轨道 Aᵗv；几何分类；**高精度**：精确分数、根式、最高 1000 位小数、Aⁿ 精确幂、与双精度逐项对比误差 |
| **复变函数映射** | 任意 f(z) 表达式实时编译；定义域着色（增强相位图 / 纯相位 / 棋盘格）；网格线的像及从恒等映射到 f 的连续变形；探针显示 f′(z) 与柯西–黎曼检验；可拖动围道验证幅角原理 |
| **常微分方程轨线** | 相平面：方向场、流动粒子、点击生成轨线（自适应 Dormand–Prince）、平衡点求解与分类、鞍点分界线、零倾线、时间序列，参数滑块实时驱动全部内容；三维：洛伦茨等 6 个奇怪吸引子、蝴蝶效应、最大李雅普诺夫指数 |
| **三体运动** | 平面牛顿 N 体问题：8 字形、拉格朗日、欧拉、Šuvakov–Dmitrašinović 周期轨道族、毕达哥拉斯问题等预设；4 种积分器对比；能量 / 角动量 / 动量守恒监测；时间反演；暂停后拖动天体和速度箭头编辑初值；可增删天体 |

所有图形都由代码在浏览器中逐帧计算并绘制（Canvas 2D），没有任何预渲染图片或视频；运行时零依赖（原生 ES 模块，无需构建）。

### 开启页面

`#/`（不带地址时默认打开）：背景是实时积分的阻尼单摆相平面（点击放出粒子），四张模块卡片里分别实时运行矩阵变形、定义域着色、洛伦茨吸引子与 8 字形三体轨道；下方有计算精度设置和 9 个精选示例（斐波那契矩阵、双精度会算错的矩阵、Γ 函数、霍普夫分岔、洛伦茨吸引子、毕达哥拉斯三体问题……）。看过任一模块后会出现“继续”按钮。设置里可以关掉开启页面，此后直接打开上次的模块。

### 计算精度

默认使用 IEEE 754 双精度（约 16 位有效数字）。在设置（侧栏齿轮）、页头的精度标记、开启页面或快捷键 `P` 打开**高精度**，可选 20 / 50 / 100 / 300 / 1000 位有效数字，选择保存在本机浏览器中：

- **矩阵**：矩阵元素按输入的原式求值（`0.1`、`1/3`、`1e-20` 是精确有理数，`sqrt(3)/2`、`cos(pi/7)` 求到所选位数）。四个元素都是有理数时，行列式、迹、特征多项式、逆矩阵是精确分数，特征值、特征向量、奇异值、条件数给出化简后的根式，如斐波那契矩阵 λ = (1 ± √5)/2、κ = (3 + √5)/2；所有量都有所选位数的十进制展开（可复制）。“精确幂”计算 Aⁿ（|n| ≤ 10⁶，有理元素时为精确整数 / 分数）。“与双精度对比”逐项列出双精度结果还剩几位正确：预设“近重根” `[[1, 1], [10⁻²⁰, 1]]` 的特征值是 1 ± 10⁻¹⁰，双精度却把它算成二重根；预设“病态”的行列式 10⁻¹⁵ 在双精度下错了 11%。
- **复变**：探针改用五点差分（误差 O(h⁴)）求 f′(z)，读数显示 12 位有效数字；幅角原理沿围道加密采样。
- **常微分方程**：轨线与分界线的 Dormand–Prince 容差从 10⁻⁸ 收紧到 10⁻¹²，平衡点的牛顿迭代收敛到 10⁻¹⁴；三维吸引子的李雅普诺夫指数在 4 倍长的时间上平均。
- **三体**：积分器默认相对误差容限从 10⁻¹⁰ 收紧到 10⁻¹³，守恒量显示 12 位。

带 `hp=50` 参数的链接会为打开它的人开启高精度；高精度下用 🔗 复制的链接会自动带上这个参数。

整个软件打包成了**一个 HTML 文件**：[`dist/mathscape.html`](dist/mathscape.html)（约 380 KB）。下载后双击，用浏览器打开即可，不需要安装任何东西，也不需要联网。

- 在 GitHub 上打开 [这个文件](https://github.com/xhc144/claude-lab/blob/main/mathscape/dist/mathscape.html)，点右上角的 **Download raw file**（下载图标）；
- 或者用命令行：`curl -LO https://raw.githubusercontent.com/xhc144/claude-lab/main/mathscape/dist/mathscape.html`

需要一个现代浏览器：Chrome / Edge 99+、Firefox 112+、Safari 16+。

## 从源码运行

源码版本使用 ES 模块，浏览器不允许从 `file://` 加载，所以要通过 HTTP 打开（单文件版没有这个限制）：

```bash
cd mathscape
npm start                 # 零依赖静态服务器（Node ≥ 18），打开 http://127.0.0.1:5173/
# 或：node scripts/serve.mjs --port 8080 --host 0.0.0.0
# 或任何静态服务器，例如：python3 -m http.server 5173
```

`npm start` 不需要先 `npm install`——运行时没有任何第三方依赖。

各模块的地址：`#/`（开启页面）、`#/matrix`、`#/complex`、`#/ode`（`#/ode?mode=3d` 为三维）、`#/threebody`。界面状态（矩阵元素的原式、动画路径、函数表达式、参数 a、ODE 方程与参数与轨线起点、三体预设与积分器……）会同步到地址栏，右上角的 🔗 按钮复制链接即可分享当前状态；📷 按钮导出当前画面为 PNG。控制面板的每一节都可以点标题折叠，折叠状态按模块记住。

### 快捷键

### 单元测试验证的数学结论（`tests/unit/`）

- **表达式语言**：运算优先级与结合性（`-2^2 = -4`、`2^3^2 = 512`）、隐式乘法（`2x`、`x(x+1)`、`xy`）、Unicode 运算符、带位置的中文错误提示；生成的代码无法访问全局对象。
- **复函数**：`exp∘log = id`、sin²+cos² = 1、二倍角、tan = sin/cos、反三角函数回代、主值平方根、整数与一般幂、Smith 除法与除零、Γ(5) = 24、Γ(½) = √π、Γ(−½) = −2√π、|Γ(i)|² = π/sinh π、Γ(z+1) = zΓ(z)；编译出的解析函数满足柯西–黎曼方程；幅角原理计数（z³−1、1/z、有理函数、sin z 在 |z| < 10 内 7 个零点）。
- **线性代数**：300 个随机矩阵上 Av = λv、特征值之和 / 积 = 迹 / 行列式；闭式 SVD 重构 M = UΣVᵀ（U、V 正交，σ₁ ≥ σ₂ ≥ 0，σ₁² + σ₂² = ‖M‖²_F）；极分解 M = QP；极分解插值全程 det > 0；斐波那契矩阵的幂；几何分类；exp(log M) = M、M⁰·³M⁰·⁷ = M、剪切矩阵的平方根，没有实对数的矩阵被识别；SVD 分步路径在 t = ⅓ 处等于 Vᵀ、终点等于 M。
- **任意精度**：π 到 100 位、e、√2、ln 2、ln 10、黄金比到 50 位与参考值逐位相同；sin、cos、exp、tanh、asinh、atanh 等与参考值一致，4·atan 1 = 2·asin 1 = acos(−1) = π（100 位）；ln(1 + 10⁻³⁰)、sinh(10⁻²⁰) 不因相消丢位，sin π、cos(π/2) 给出 0 而不是 10⁻⁶⁰ 量级的噪声；0.1 + 0.2 = 3/10 精确；定义域错误（ln(−1)、1/0……）抛出异常；斐波那契矩阵的根式、近重根矩阵的精确特征值、F(100) 与 F(10000)（2090 位）。
- **常微分方程**：RK4 收敛阶 ≈ 4；Dormand–Prince 在指定容差内、可正反向积分、精确落在终点；Hermite 加密后的点仍在解曲线上；平衡点分类（鞍点 / 结点 / 焦点 / 中心 / 退化结点）；单摆、范德波尔、Lotka–Volterra 的平衡点；窄牛顿吸引域的根不会漏掉；零倾线不把极点误判为零点；洛伦茨系统最大李雅普诺夫指数 ≈ 0.906。
- **N 体**：开普勒椭圆一周期后回到起点、半周期位于远日点；所有预设的能量、角动量、动量、质心守恒；8 字形、拉格朗日、欧拉解与 5 条 Šuvakov–Dmitrašinović 轨道在一个周期后回到初值（误差受发表的有效数字限制）；8 字形的“编舞”性质；毕达哥拉斯问题最终抛出质量 3 的天体；Yoshida / RK4 收敛阶 ≈ 4、Verlet ≈ 2、辛积分器长期能量误差有界；Verlet 的严格时间可逆性；软化引力的力与势一致。
- **渲染数学**：自适应曲线采样在 log z 的割线和极点处断开；OKLCH 色轮亮度恒定；分块渲染的定义域着色与一次性渲染逐字节相同；像素颜色等于 arg f(z) 的色相；极点白、未定义灰。

## 数学与数值方法

### 表达式编译（`src/core/expr.js`）
递归下降解析器生成语法树，再生成 JavaScript 代码并用 `new Function` 编译。复数表达式被展开成只操作实部 / 虚部浮点数的直线型代码，每次求值零内存分配，因此定义域着色可以每帧求值数十万次。所有标识符都经过白名单检查。

### 复变函数（`src/core/complex.js`、`domaincolor.js`、`curves.js`）
- 初等函数取主值分支（log、sqrt、pow 的割线在负实轴，arg ∈ (−π, π]）；Γ 函数用 Lanczos 近似（g = 7）加反射公式；除法用 Smith 算法避免溢出。
- 定义域着色：色相取 arg f(z)，在感知均匀的 OKLCH 色轮上（亮度恒定，必要时只降低彩度以落入 sRGB 色域）；“增强相位图”叠加 log₂|f| 与 12 个辐角扇区的锯齿明暗，并按像素足迹淡化过密的等高线以消除摩尔纹。交互时先渲染低分辨率，停止操作后在多帧内分块完成全分辨率渲染，不阻塞输入。
- 网格线的像：自适应二分采样，直到线段短于约 1.6 像素；二分到最大深度仍然很长的线段被判定为跳跃（割线、极点）并断开。
- 探针用中心差分计算 Wirtinger 导数 ∂f/∂z = (f_x − i f_y)/2 与 ∂f/∂z̄ = (f_x + i f_y)/2，后者为零即柯西–黎曼方程成立。
- 幅角原理：沿圆周累加 f(γ) 的辐角增量，相邻采样点转角超过 0.4 弧度时自适应细分，结果为内部零点数减极点数。

### 线性代数（`src/core/linalg.js`）
2×2 特征值用数值稳定的求根公式；SVD 用 Blinn 的闭式分解（把矩阵拆成相似旋转与相似反射之和）；极分解 M = QP 由 SVD 得到。“极分解插值” R(tθ)·((1−t)I + tP) 让旋转部分刚性转动、行列式保持为正；线性插值 (1−t)I + tA 则保持特征方向不变——当 det A < 0 时任何连续路径都必须穿过奇异矩阵。

“指数插值” Aᵗ = exp(t·log A)：把 M 写成 mI + K（m = tr M/2），由凯莱–哈密顿定理 K² = (m² − det M)·I，于是 exp 与 log 都化成 αI + βK 的闭式（双曲、三角或幂零三种情形）。实对数存在当且仅当 det > 0 且没有负特征值（−kI 除外，它等于 k 倍的 180° 旋转）。“SVD 分步”依次播放 R(tθ)、沿坐标轴伸缩到 Σ、R(tφ)，det < 0 时把反射放进 Σ 的负的第二个奇异值。

### 任意精度（`src/core/bigreal.js`、`hpmatrix.js`）
数分两种：精确有理数 n/d（BigInt，最简），以及 m·10ᵉ 形式的十进制近似（保留工作位数 W = 显示位数 + 12 位保护位）。四则运算、整数次幂、完全平方数的开方保持精确，其余结果按 W 位舍入。初等函数在定点整数上计算：π 用 Machin 公式，ln 2 = 2 atanh(1/3)，ln 10 = 3 ln 2 + 2 atanh(1/9)；exp 先减去 k·ln 2 再缩小 2¹² 倍做泰勒展开、平方 12 次；ln 先按 10 和 2 的幂约化到 [0.7, 1.42] 再用 atanh 级数；sin/cos 按 π/2 约化到 |r| ≤ π/4；atan 用三次半角公式缩小参数。结果可能远小于参数时（ln 在 1 附近、sin 的小参数）自动加位；精确参数的结果有效位不足时加位重算，近似参数的结果低于其自身不确定度时给出 0。

矩阵的闭式：λ = (T ± √Δ)/2，√Δ 用小素数试除提取平方因子后约成 (A ± B√r)/C；特征向量取 (2b, d − a ± √Δ)；奇异值 σ = (√P ± √Q)/2，其中 P = (a+d)² + (c−b)²、Q = (a−d)² + (b+c)²；条件数 κ = (P + Q + 2√(PQ))/|4 det A|。较小的特征值与奇异值用 D/λ₁、|D|/σ₁ 计算，避免相消。Aⁿ 写成 Nⁿ/δⁿ（N 为整数矩阵、δ 为公分母）用整数快速幂计算，最后只按 δ 的素因子约分，代替对上万位整数做欧几里得算法（3000 次幂从 1 秒降到 11 毫秒）。

### 常微分方程（`src/core/ode.js`）
- 轨线：Dormand–Prince 5(4) 自适应积分（FSAL、PI 步长控制，相对误差 10⁻⁸），用每步的导数做三次 Hermite 插值来加密绘图点。
- 平衡点：在 48×48 网格上找两个分量同时变号的格子作为牛顿迭代起点（保证找到所有横截零点），再加均匀网格起点；数值雅可比矩阵的迹 τ、行列式 Δ、判别式 τ² − 4Δ 决定类型。
- 分界线：从鞍点沿特征向量偏移 10⁻⁵ 倍视野，不稳定流形正向、稳定流形反向积分。
- 零倾线：行进方块（marching squares），并在插值点复查函数值以排除穿过极点的伪变号。
- 李雅普诺夫指数：Benettin 方法（参考轨线与相距 10⁻⁸ 的邻近轨线，每 0.5 个时间单位重新归一化）。

### N 体问题（`src/core/nbody.js`）
G = 1 的平面牛顿引力（可选 Plummer 软化，力与势一致）。积分器：自适应 Dormand–Prince 5(4)（默认，相对误差 10⁻¹⁰）、Yoshida 4 阶辛积分、速度 Verlet（2 阶辛、严格时间可逆）、经典 RK4。所有预设在加载时变换到质心系。

| 场景 | 帧率 |
