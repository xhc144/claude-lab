# 薪火纪 EMBERSTACK

一款原创的浏览器卡牌堆叠策略游戏。灰雾吞没了世界，你带着几个幸存者走进一片河谷：把卡牌叠在一起来采集、建造、研究、探索与战斗，熬过黑夜与寒冬，在七片土地上重新点燃文明的火种——或者把营地交给一位**真正会思考的 AI 玩家**，看它从零开始建设文明，并在日志里写下它的每一个想法。

- 纯前端、零运行时依赖：原生 ES modules + Canvas 2D + WebAudio
- 所有美术（316 张卡面插画、地表、光影、特效）与音乐、音效都由代码实时绘制与合成，没有任何图片或音频文件
- `dist/emberstack.html` 是单文件版本，下载后双击即可离线游玩

## 运行

```sh
cd emberstack
npm start                 # http://127.0.0.1:5190
npm run build             # 生成 dist/emberstack.html（单文件、可离线）
```

源码版需要通过 HTTP 打开（浏览器不允许从 `file://` 加载 ES modules）；单文件版可以直接打开。

## 玩法

| 系统 | 内容 |
| --- | --- |
| 堆叠与配方 | 316 张卡牌、238 个配方（187 个合成配方 + 51 个采集/探索配方，其中 34 个隐藏配方，只能靠尝试、残卷线索或 AI 的实验发现）。配方按“可互换的卡组”匹配，允许多余的劳力、工具与光源 |
| 昼夜与光 | 一天约 72 秒。夜里没有光的地方无法工作（生火、扎火把、立火把桩除外）；篝火、火把桩、灯柱、灯塔、长明灯照亮营地；火把与灯笼可以随身携带。暗影在光里被灼烧 |
| 灰雾 | 世界的倒计时：随时间与暗影上涨，灯龛、石冢、庆典、灯塔与大薪火让它退散。某些关卡灰雾涨满即失败 |
| 生存 | 每个黎明吃饭（饥饿两次即死亡）、燃料燃烧、食物腐坏、孩子长大、植物再生；四季轮转，冬天作物休眠、篝火加倍耗柴、寒冷伤人 |
| 科技 | 6 个时代、48 项科技，用“灵感”卡研究；解锁建筑、职业（21 种人物）、工具与装备 |
| 探索 | 17 种地域卡，派人探索会带回资源点、动物、同伴、宝物，也可能遭遇伏击；部分地域需要光源或舟 |
| 战斗 | 穿刺 / 钝击 / 光芒三种伤害，护甲、暗影、飞行、灼烧、嘲讽、召唤等特性；巢穴、瞭望塔、城墙；8 个首领各有弱点 |
| 经济与事件 | 集市、商队、20 种随机事件（流浪者、难民、瘟疫、日食、陨石、洪水……），每个选项都写明代价 |

### 关卡与模式

- **战役**：7 章 28 关——余烬（河谷）、林海、盐沼、铜铁之山、霜原、雾海群岛、灰烬王座。每片土地有自己的地形、资源、敌人、规则（永夜矿井、洪水、极寒、海上航行……）、目标与三星评价，终章需要分三阶段点燃大薪火并击败灰烬之王
- **远征**：选择土地、难度（1–5）、种子与 10 种修正（永夜、饥荒、孤身、兽潮、浓雾、极寒、丰饶、商路、急行、博学），程序生成地图与目标
- **无尽**：每三夜一次袭击、逐渐增强，记录坚持的天数
- **挑战**：7 个战役关卡的残酷变体

此外还有新手教程（前三关会随玩家或 AI 的操作自动推进）、图鉴（卡牌、配方、科技、敌人、玩法说明）、36 项成就、设置、自动存档与存档导入导出。

## AI 玩家

AI 与玩家遵守同一套规则：它只能看到场上的卡牌，只能通过与鼠标相同的 `act*` 接口（拿起、放下、点击、研究、交易、选择）改变世界，每个动作之间有约 0.38 秒（游戏时间）的间隔。单元测试会静态检查 `src/ai/` 中没有任何直接修改游戏状态的代码。

- **感知**（`ai/world.js`）：把棋盘整理成库存、在途产出、空闲/卡住的工人、威胁、光照、食物与燃料预算、离冬天的天数等
- **规划**（`ai/planner.js`、`ai/knowledge.js`）：需求驱动的生产规划——为每个需要的物品比较采集、种植、探索、狩猎、购买、合成与先研究科技等方法的代价，递归展开原料并为它们预留卡牌
- **决策**（`ai/brain.js`）：每秒重新评估生存（口粮、燃料、寒冷、黑暗）、关卡目标、人口、研究、贸易、训练、探索与实验的优先级，按策略性格加权，分配给工人并逐步执行
- **战术**（`ai/tactics.js`）：用兰彻斯特式战力估计决定集结、增援、撤退到光里、拦截与强攻，避开沉睡的首领直到准备充分
- **实验与记忆**：AI 会根据名字与材料猜测隐藏配方，记住失败的组合；发现的配方在本地长期保存
- **策略**：均衡 / 速通 / 稳健 / 探索 / 征伐，可随时切换
- **控制**：一键托管、暂停、1–16 倍速、自动进入下一关、实时决策日志与当前目标；玩家拖动任何卡牌即接管，一键交还

### 基准（无头运行，与浏览器中是同一套代码）

| 场景 | 结果 |
| --- | --- |
| 战役 28 关 × 均衡策略 × 3 个种子 | 84 局胜 81 局 |
| 战役 28 关 × 5 种策略 × 1 个种子 | 140 局胜 136 局（失败集中在“速通/征伐”这类偏激性格碰上首领关） |
| 远征（7 种土地 × 难度 1/3/5 × 2 个种子） | 难度 1 全胜；难度 3 大多获胜；难度 5 是真正的考验 |
| 无尽 | 通常能坚持 35–60 天以上 |

```sh
node scripts/ai-run.mjs 2-4 --log                 # 在终端里看 AI 玩一关
node scripts/ai-bench.mjs --seeds 3               # 全部关卡 × 5 种策略 × 3 个种子
node scripts/ai-bench.mjs --modes --objs          # 远征 / 无尽 / 挑战
```

## 测试

```sh
npm run test:unit    # 数据完整性、核心机制、确定性、存读档、模式生成、AI 不作弊检查
npm run test:ai      # AI 用均衡策略通关每一个战役关卡
npm run test:e2e     # Playwright：标题、拖拽、AI 通关、接管与交还、科技树/图鉴/设置、远征、手机布局
npm run test:dist    # 同一套端到端测试跑单文件版本
npm run lint         # 语法与导入检查，确认 dist/ 已更新
```

## 结构

```
src/
  data/     卡牌、配方、科技、关卡、事件、贸易、成就
  sim/      规则引擎（确定性、固定步长、无 DOM）：匹配、任务、战斗、生物、昼夜、经济、目标
  ai/       感知、知识与成本模型、规划、执行、战术、策略、大脑
  render/   绘画原语、人物与生物、场景道具、卡面插画、卡框与缓存、地表、棋盘、特效、图标
  ui/       HUD、菜单、图鉴、输入、教程、存储
  audio/    程序化音效与音乐
  modes/    远征、无尽与挑战的关卡生成
scripts/    本地服务器、单文件构建、AI 运行与基准、检查
tests/      unit/、e2e/ 与截图用的 harness/
```

## 美术风格

“灯下木刻”：墨线勾边、渐变上色、木刻排线、来自火光一侧的轮廓光、暗角与纸纹。每张卡面由人物、生物、建筑、道具与背景等绘制原语组合而成，按种类使用不同材质的卡框（皮革、石板、铁、漆金……）与稀有度宝石，并按缩放档位缓存为位图。
