# 万象 MYRIAD — 文明演化与创世沙盒

> 你没有名字——直到他们为你命名。

《万象》是一款在浏览器里运行的创世模拟沙盒。一块漂浮在虚空中的大地会**自己运转**：板块隆起山脉，风把海上的水汽带上陆地，雨水汇成河流、侵蚀河谷；带着基因组的生物觅食、捕猎、繁殖、突变，被隔离的种群分化成新物种，聪明而合群的物种会觉醒出智慧；部落点燃篝火、开垦农田、建立城市，发展出各自的语言、国旗、政体与价值观，研究横跨十一个时代的科技，通商、结盟、宣战、分裂、革命，直到有一天造出星舟离开这个世界——或者在核火与温室中毁灭。

你是这个世界里一股**无名的力量**。你可以只是看着，也可以出手：隆起群山、降下甘霖、劈下雷霆、投下陨石、创造新物种、点化智慧、向城市低语一种观念、挑起或平息战争、打开虚空之门……

它和传统文明游戏最大的不同是：**你在文明附近的每一次作为，都会被他们当作征兆记住。** 看惯雷霆与陨石的民族会把你奉为「雷霆之主」「天罚者」，受过甘霖与赐福的民族会称你「慈光之神」，见过虚空之门和时之泡的民族会追问你是谁。印象足够深时，他们会给你取名、为你立教。同一个你，在不同民族的神话里可以是完全不同的神。

所有画面、名字、语言、旗帜、音效都由代码在运行时程序化生成；运行时零第三方依赖。

## 下载即用

整个游戏打包成了**一个 HTML 文件**：[`dist/myriad.html`](dist/myriad.html)（约 600 KB）。下载后双击用浏览器打开即可，不需要安装、不需要联网。

- 在 GitHub 上打开[这个文件](https://github.com/xhc144/claude-lab/blob/main/myriad/dist/myriad.html)，点右上角的 **Download raw file**；
- 或：`curl -LO https://raw.githubusercontent.com/xhc144/claude-lab/main/myriad/dist/myriad.html`

需要一个现代桌面浏览器（Chrome / Edge 100+、Firefox 115+、Safari 16+）。手机可以打开和观看，但这是为鼠标和大屏设计的游戏。

## 从源码运行

```bash
cd myriad
npm start          # 零依赖静态服务器（Node ≥ 18），打开 http://127.0.0.1:5181/
```

源码是原生 ES 模块，浏览器不允许从 `file://` 加载，所以要经过 HTTP（单文件版没有这个限制）。`npm start` 不需要先 `npm install`。

地址栏参数可以跳过标题画面直接开局：`?autostart=1&seed=42&preset=archipelago&start=tribes&size=small&speed=2`。

## 玩法

### 开局

标题画面上选择：

- **地理**（9 种，带实时预览）：群陆、盘古、千岛、双生、环海、群峰、沧海、霜星（冰封星球）、赤砂（荒漠星球）；可微调陆地比例、山地、气温、湿度和种子。
- **起点**：原初之海（只有海里的简单生命，登陆、飞行、智慧都要靠演化）· 万物繁盛 · 部落黎明 · 王国林立 · 荒芜之地（一切由你创造）。
- **模式**：**沙盒**（神力无限）或 **神途**（神力只来自崇拜你的信徒，需要经营信仰；回应城市的祈祷能获得更多神力）。
- **大小**：小 240×150 / 中 320×200 / 大 420×260 格。
- **实验室**：10 个预设情景——孤岛进化、智慧的种子、双雄、永冬、文明熔炉、大灭绝之后、温室末日、天外来客（120 年后彗星撞击，他们能否及时造出火箭）、万神殿、从零开始。

## 世界如何运转

时间以**季**为步长（一年四季）。所有模拟都是确定性的（带种子的随机数发生器），不依赖 DOM，可以在 Node 里无界面运行。

**大地与气候**
- 板块构造生成地形：碰撞带隆起山脉与火山弧，叠加多尺度噪声；侵蚀会缓慢切出河谷。
- 两个方向的风带扫过大陆，把海上的水汽带上陆地，山脉投下雨影；气温随纬度、海拔、季节（南北半球相反）变化，划分出 20 种生物群系。
- 优先洪泛算法计算排水：每个陆地格都流向大海，汇成河流与湖泊；暴雨会引发洪水。
- 植被与浮游生物逐格生长、被啃食、被火烧；野火会蔓延。
- 全球气候受 CO₂（来自工业与火山，被植被和海洋吸收）和尘埃（来自陨石、火山、核爆）影响；变暖会抬升海平面淹没海岸，冰河期会让海退。
- 地震、海啸、火山喷发与熔岩流、陨石坑都会真实地改变地形。

**生命**
- 每个生物是一个个体，带 15 个基因（体型、速度、食性从滤食到肉食、耐热、陆栖度、智力、群居性、繁殖策略……）。它们觅食、捕猎、逃跑、迁徙、繁殖，后代带着突变。
- 当一个种群与祖先的遗传距离足够远，就分化成新物种，自动获得一个中文名（如「林青繁鸟」）和拉丁学名，并记录在生命之树上。
- 原初之海的生命可以自己登陆、长出翅膀；食物网会自我调节（「杀死赢家」式的密度疾病防止单一物种独霸）。
- 足够聪明、足够合群的物种可能**自然觉醒**出智慧，建立第一个部落。

**文明**
- 每个智慧种族、每个国家都有程序生成的**语言**（音系 + 中文音译规则），所有国名、城名、人名都从这门语言里来；分裂出去的国家语言会漂变。国旗按国家的价值观程序化绘制。
- 城市按地形、水源、资源选址、成长、升级（营地 → 村落 → 城镇 → 城市 → 大都会 → 超级都市），在周围开垦农田、矿井、道路；领土由城市影响力的多源最短路划定。
- **11 个时代、52 项科技**（燧石纪 → 星海纪），研究方向受文化价值观和本地资源影响，邻国知道的技术更容易学会；24 种建筑、15 座奇观，最后是星舟方舟。
- 贸易路线（陆上商队、海上航线）带来财富，也传播思想、宗教、技术——和瘟疫。
- 国家有政体（11 种：部落、酋邦、王国、帝国、神权国、共和国、商业寡头国、民主联邦、军政府、公社联盟、技术官僚国）、统治者及其性格、四维价值观（尚武 / 集体 / 传统 / 虔诚，外加开放度）。外交关系有接触、好感、贸易、结盟与战争；战争中军队沿 A* 路径行军、野战、围城、焚城，后期有核武器。
- **思潮**（18 种观念：祖灵崇拜、君权神授、重商主义、共和理想、人文主义、自由主义、民族主义、公社主义、生态主义、技术乌托邦、超越主义……）沿城市间的联系传播，与政体冲突时引发动乱、革命、内战与分裂。
- **神话生成**：宗教不是预设的。民族目击的征兆被累积记忆，自然现象和你的神力都会催生宗教，教义的神性（愤怒 / 仁慈 / 神秘 / 创造）和你的称号由他们看见的东西决定；宗教会扩散、改宗、分裂，也会出现先知自创的宗教。
- 伟人（科学家、艺术家、商人、先知、探险家、名将）、黑暗时代、瘟疫、饥荒、迁徙、考古（发掘失落文明的遗迹）、26 种随机事件（古钟自鸣、预言之子、无夏之年、核电站熔毁……），以及会游荡的巨兽、龙卷风、彗星。

**画面与声音**
- Canvas 2D 渲染：地形分块缓存（每格 4 像素，双线性插值的光照与海岸），山体阴影、河流、季节色调、两层反向漂移的云、天气粒子、城市与军队的程序化精灵、国境线与标签；可选的昼夜循环（夜半球的城市亮起灯光）；12 种叠加层。
- WebAudio 程序化声音（没有任何音频文件）：环境音底、风声与浪声，一段缓慢游走的钟声旋律（音阶随世界最先进的时代变化），以及雷鸣、陨石、战鼓、钟声等事件音效。

│   │   ├── civ/   nation · city · territory · tech · economy · war · diplomacy
│   │   │          religion · ideas · society · people · civ       文明
│   │   ├── powers · events · entities · achievements · stats · chronicle
│   │   └── serialize                                             确定性存档
│   ├── render/    地形分块、相机、叠加层、云、粒子特效、精灵
│   ├── ui/        标题画面、HUD、侧栏、检视器、图表、弹窗、实验室情景
│   └── audio/     程序化音效

源码约 1.24 万行 JavaScript，没有任何运行时依赖。

## 现状与已知不足（如实说明）

已经完成并可玩：上面列出的全部系统都已实现、互相联动，并通过了单元测试和端到端测试；单文件版可以离线运行。但它仍然是一个由一个人（一个 AI）在有限时间内写成的模拟，以下是我清楚知道的不足：

- **平衡性只做了粗调。** 科技节奏、战争频率、宗教扩散速度、生态稳定性都是用少量种子反复跑出来调的，换一个种子或地理可能出现偏快 / 偏慢、某个物种独霸、某个国家早早统一大陆之类的情况。作为参考，「王国林立」开局（小地图、种子 11）里最先进的文明约在第 380 年进入蒸汽纪、700 年进入原子纪、970 年进入星海纪；「部落黎明」开局大约要两倍时间（种子 7：铜火纪 190 年、蒸汽纪 920 年）。神途模式的神力收支尤其粗糙。
- **文明是城市级而不是个人级模拟。** 生物是逐个体模拟的，但人口是城市里的数字；没有逐个市民、家族、职业的模拟。伟人和统治者是个体，有生平记录。
- **海战、空战被简化**成带「舰队」标记的军队；没有独立的海军调度或补给线。
- **后期性能跟不上高速档。** 世界越繁荣，每一季要算的东西越多：小地图 600 年后模拟一季约 10 ms，中地图 400~500 年后约 18 ms（Node 无界面测量）。在开发环境里（2.1 GHz 服务器 CPU、无 GPU 的无头 Chromium），小地图 600 年后「5×」档（标称 160 季/秒）实际只有约 29 季/秒，「极速」档约 39 季/秒；早期世界快得多。普通台式机会更快，但我没有在真实硬件上测过；大地图后期肯定达不到标称速度。
- **太空时代的终点**是星舟方舟升空（一部分人口离开世界）；没有「星际」玩法，也没有胜利条件——这是沙盒，故事由你和世界决定何时结束。
- **声音**是振荡器与噪声合成的音效和环境音，不是作曲的音乐。
- **手机**能打开、布局不溢出、可以双指缩放和观看，但神力工具栏和侧栏在小屏上很挤，体验远不如桌面。
- 名字由程序生成，偶尔会出现读起来别扭的音译组合。
- 没有多人、没有模组接口、没有本地化（界面只有中文）。
