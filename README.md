> 本仓库还包含 **[数境 MathScape](mathviz/README.md)**：一个零依赖的交互式数学可视化网页应用（矩阵线性变换、复变函数映射、常微分方程轨线、三体运动），带单元测试与端到端测试。运行：`cd mathviz && npm start`，然后打开 http://127.0.0.1:5173/ 。

## 《对称的语言》—— 抽象代数宣传片

一支约 3 分 40 秒、1080p / 30fps 的抽象代数（但不止抽象代数）宣传片。全部画面与配乐都由本仓库的代码程序化生成，没有使用任何外部素材。

成片：`output/abstract_algebra_promo_web.mp4`（1080p，约 95 MB 的网络版。用下文命令可以重新渲染出约 220 MB 的高码率母版 `output/abstract_algebra_promo_1080p.mp4`）

### 技术

- **矢量绘制**：[skia-python](https://github.com/kyamagu/skia-python)，所有场景都在 1920×1080 的设计坐标中绘制
- **逐像素着色**：用 [Numba](https://numba.pydata.org/) 写 CPU 着色器，包括雪花冰晶、双曲铺砌（反射折叠）和魔方的光线步进渲染（软阴影、AO、地面反射）
- **数学排版**：matplotlib mathtext
- **模拟与预计算**：Reiter 雪花元胞自动机；Littlewood 多项式的根（批量求伴随矩阵特征值）；E₈ 的 Coxeter 平面
- **配乐**：`studio/audio.py` 用 numpy/scipy 合成（polyBLEP 锯齿波 pad、加法合成钢琴、FM 钟声、Karplus–Strong 拨弦、鼓组、riser 和 impact 音效、卷积混响），所有重拍都对齐剪辑中的时间点
- **后期**：多尺度辉光（bloom）、暗角、胶片颗粒；重拍时加推镜和色散效果

### 运行

详细步骤、环境要求和常见问题见 **[使用说明.md](使用说明.md)**。最快的用法：

```bash
bash build.sh preview   # 低清预览版，约 5 分钟
bash build.sh           # 1080p 正式版，4 核约 30 分钟
```

`studio/timeline.py` 里的 `EDIT` 决定场景顺序和交叉淡化时长。每个场景都是 `studio/scenes/` 下的一个类，只依赖本场景内的时间 `t`，所以可以随意取任意时刻单独渲染。
