## 打开方式

**直接双击**：`dist/index.html` 可以从磁盘直接打开（`file://`），完全离线可用；只有“与 GitHub 实时同步”那一行需要联网，断网时自动显示快照数据。

**本地服务器**：

```bash
cd personal-site
npm start          # 零依赖静态服务器，打开 http://127.0.0.1:5180/
```

**部署**：`dist/` 是一个纯静态目录，原样上传到 GitHub Pages、Vercel、Netlify 或任何静态托管即可。

推荐桌面版 Chrome / Edge / Firefox / Safari 16+，戴耳机，按 F11 全屏。手机上会自动降低粒子数、关闭辉光后期。系统设置了“减少动态效果”时，动画会收敛。

## 技术

- **three.js 0.186**：一个 `THREE.Points` 承载全部粒子。每次切换章节时，CPU 按与着色器完全相同的公式算出当前显示位置作为起点，GPU 在顶点着色器里做带错峰与涡旋的变形；三叶结纤维与 Hopf 纤维的位置在着色器里由 S³ 上的点实时计算。后期：UnrealBloom → ACES 色调映射 → 色散、暗角、胶片颗粒。
- **三叶结 Seifert 曲面**（`src/universe/fiber.js`）：先在仿射曲线 z² + w³ = 1 上按局部面积重采样，再用加权流 (z, w) ↦ (s³z, s²w) 推到 S³ 上；旋转 (z, w) ↦ (e^{iθ/2}z, e^{iθ/3}w) 得到任意一页 F_θ；从 (i, 0) 做球极投影到 ℝ³。
- **相位肖像**：一个白名单语法的小解析器把 f(z) 编译成 GLSL（用于绘制）和 JS 闭包（用于光标读数），不会执行任何其他代码。
- **KaTeX** 排版公式；**esbuild** 把一切打包成一个经典脚本，所以 `file://` 也能运行。
- 西文字体 Space Grotesk 与 JetBrains Mono（SIL OFL 1.1，许可证在 `src/assets/fonts/`）；中文使用系统字体。

## 开发与验证

```bash
npm install                 # three、katex、esbuild、字体包、@playwright/test
npm run dev                 # 监听源码并在 http://127.0.0.1:5180/ 提供 dist/
npm run build               # 生成 dist/
npm run test:unit           # 15 个单元测试（node --test）
npm run test:e2e            # 9 个端到端测试（Playwright + Chromium，直接打开 file://）
npm run shots               # 截图巡检：34 个位置，加 --mobile 为手机尺寸
npm run zip                 # 生成 release/xhc144-site.zip
```

单元测试验证的结论：三叶结在 S³ 上且满足 z² + w³ = 0，纤维采样点满足 arg(z² + w³) = 0、旋转后为 θ；FFT 与直接 DFT 一致且可逆；双摆的 RK4 积分 10 秒能量相对误差 < 10⁻⁵，线性化后的两个简正频率 ω² = g(2 ± √2)；S₃ 标准表示是同态，特征标为 2、0、−1，每个反射固定对应顶点；分步傅里叶法在吸收层外保持归一化，T + R = 1，平均能量低于势垒时仍有可观的隧穿；表达式语法的优先级、隐式乘法和白名单；魔群的阶；F₁₂ = 144 = 12²；2027 是质数；mit-ocw-notes 的册数与页数合计。

端到端测试覆盖：启动序列（真实预计算的日志与耗时）、静音与开声音两种进入方式、13 台仪器全部挂载、滚动到第 3 维后粒子变成 Milnor 纤维、终端命令与跳转、彩蛋计数与彩蛋面板、实验室视图、相位肖像拒绝非法输入、手机宽度无横向溢出，以及全程控制台无错误。

## 已知限制

- 这台开发机没有 GPU，截图和测试使用软件渲染（SwiftShader，约 2 帧/秒），因此动画流畅度只在有 GPU 的真实浏览器里才能体现；没有在真机手机上验证过。
- GitHub API 未登录时每小时 60 次请求，超过后档案区自动退回快照。
- 声音需要用户点击“开启声音”后才能播放（浏览器的自动播放策略）。
