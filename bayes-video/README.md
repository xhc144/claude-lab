# 贝叶斯统计：让证据改变判断

一支讲贝叶斯统计的中文动画视频。深色背景配霓虹光效，粒子汇聚成标题，概率曲线随每一次投篮实时变形，后验地形图上随机游走的点最后聚成一团样本云。内容从一张阳性化验单讲起：为什么准确率九成的检测，阳性后真有病的概率只有 9%？把概率换成一千个人，看清“先验”被忽略在哪里；再从同一个交集的两种写法推出贝叶斯公式，看后验怎样变成下一次的先验。然后把未知的命中率 θ 当成有分布的量，一球一球地更新；比较三种先验在数据增多时怎样收拢，讲 Beta 分布“加上次数就行”的算法和加权平均；说明可信区间能回答什么、和置信区间有什么不同；最后讲参数一多公式算不出来时，MCMC 为什么只靠后验的比值就能抽样。

画面、字幕、铺底音乐全部由本目录的代码生成；配音用阿里云百炼的通义千问语音合成（模型 `qwen-audio-3.0-tts-plus`，音色龙安灵心），密钥读环境变量 `DASHSCOPE_API_KEY`；配音合成后，再用通义千问语音识别（`qwen3-asr-flash`）回听核对。

成片：[`output/bayes.mp4`](output/bayes.mp4)（11 分 01 秒，1080p30，H.264 + AAC，约 38 MB，11 个章节，中文配音，字幕压在画面里），字幕另附 [`output/bayes.srt`](output/bayes.srt)。

讲法沿用仓库里 [`explain-concepts-clearly`](../.claude/skills/explain-concepts-clearly/SKILL.md) 的要求：先说清对象（假设与证据、参数 θ、它的分布），再从定义推出公式（交集的两种写法 → 贝叶斯公式；先验 × 似然 → Beta 的加法规则），历史只保留与公式有关的两件事（贝叶斯遗稿 1763 年发表，拉普拉斯 1774 年独立提出），并标出边界：结论依赖先验，所以先验要写明、要换着试；频率学派的置信区间回答的是另一个问题。

## 章节

| 段落 | 场景类 | 内容 |
| --- | --- | --- |
| 开场 | `Opening` | 患病率 1%、灵敏度 90%、误报率 9%：阳性后有病的概率，直觉九成，实际约 9%；光点汇聚成标题 |
| 一 · 一千个人 | `Thousand` | 一千个点：10 个病人里 9 个阳性，990 个健康人里 89 个误报；9/98 ≈ 9.2%；10 × 90% 对 990 × 9%；先验 |
| 二 · 公式从哪里来 | `Formula` | 概率树；P(H∩E) 的两种写法 → 贝叶斯公式；先验、似然（竖线读“给定”）、后验、分母 P(E) 的展开；代入得 9.2% |
| 二 · 再测一次 | `Again` | 后验变先验：9.2% → 50.3% → 91.0%（两次检测相互独立）；98 人里约 8.1 个病人、8.0 个误报再次阳性；贝叶斯与普莱斯（1763）、拉普拉斯（1774） |
| 三 · 把未知的数当成随机的 | `Parameter` | 两种可能 → 零到一之间的连续取值；频率学派与贝叶斯对 θ 的不同看法；曲线下面积是概率；联盟新秀的命中率 → 先验 Beta(15, 25) |
| 三 · 一球一球地更新 | `Shots` | 似然：投中 ∝ θ，投丢 ∝ 1 − θ；后验 ∝ 先验 × 似然；六投五中，后验均值 0.43，只看数据是 0.83；平的先验给出均值 0.75 的宽后验 |
| 四 · 数据越多，先验越轻 | `Converge` | 联盟先验、平的先验、球迷先验 Beta(30, 20) 在 30、150、600 投后收拢；似然变尖；后验均值的走势；Beta(a, b) → Beta(a + h, b + m)；“事先看过 40 投 15 中”；0.395 = 40/190 × 0.375 + 150/190 × 0.400 |
| 五 · 后验能回答什么 | `Answers` | 后验 Beta(75, 115)：95% 可信区间 [0.327, 0.465]；P(θ > 0.35) ≈ 90%；下一球命中的概率 = 后验均值 ≈ 0.39 |
| 五 · 可信区间与置信区间 | `Intervals` | 20 次重复抽样的置信区间，19 个盖住真值；手上这一个区间不给出概率；可信区间的说法与代价；三种先验的区间；平的先验 [0.325, 0.480] 与 Wald 置信区间 [0.322, 0.478] 几乎一样 |
| 六 · 算不出来的时候 | `Sampling` | 命中率随距离下降的逻辑回归，两个参数 α、β；后验地形图；分母是二重积分；Metropolis：更高就走，更低按比值抽签；比值里 P(D) 约掉；几千步的样本云；数出 β 的后验 |
| 尾声 | `Finale` | 后验 ∝ 先验 × 似然；先验、似然、后验各自的含义；今天的后验是明天的先验 |

画面里的数都由 [`src/data.py`](src/data.py) 算出（`python src/data.py` 打印核对表）。化验：1000 人中病人 10、真阳性 9、误报 89，P = 9/98 ≈ 0.0918，再测两次分别为 0.503、0.910。命中率：联盟先验 Beta(15, 25)（均值 0.375，95% 区间 [0.23, 0.53]）；六投五中后 Beta(20, 26)，均值 0.435；平的先验得 Beta(6, 2)，均值 0.75。赛季 150 投 60 中：后验 Beta(75, 115)，均值 0.3947，95% 可信区间 [0.327, 0.465]，P(θ > 0.35) = 0.898。逻辑回归的 120 次投篮是用 α = 1.6、β = −0.32 模拟的（固定种子），α、β 的先验都是 N(0, 2.5²)；随机游走 Metropolis 跑 6000 步，接受率约 0.45。

## 配音

`src/tts.py` 逐句调用百炼的 SpeechSynthesizer 流式接口，句子文字、模型、音色、语速都没变时复用缓存；音频以 base64 分块放在流式事件里返回，同时取回逐字时间戳，合成时用它决定每段字幕何时出现。密钥只从环境变量或本目录的 `.env` 读取，`.env` 已被 `.gitignore` 排除，不要提交：

```bash
export DASHSCOPE_API_KEY=...      # 或 cp .env.example .env 后填入 QWEN_TTS_API_KEY
```

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `QWEN_TTS_API_KEY` | —— | 必填，也认 `DASHSCOPE_API_KEY` |
| `QWEN_TTS_MODEL` | `qwen-audio-3.0-tts-plus` | 全片约 3000 字，合成一遍约 1 元 |
| `QWEN_TTS_VOICE` | `longanlingxin` | 龙安灵心 |
| `QWEN_TTS_RATE` | `0.95` | 语速，0.5–2.0 |
| `QWEN_TTS_BASE_URL` | `https://dashscope.aliyuncs.com` | 国际站密钥用 `https://dashscope-intl.aliyuncs.com` |
| `QWEN_TTS_PROTOCOL` | `speech` | 另有 `dashscope`（多模态生成接口）和 `openai`（`/v1/audio/speech` 兼容接口） |

旁白稿在 [`src/narration.py`](src/narration.py)，每句分字幕文字和配音文字两份：字幕里写 θ、P(H|E)、0.395，配音文字写成“西塔”“P H 给定 E”“零点三九五”。两份文字的句读要一一对应，`python narration.py` 会检查。多音字和念法写在 `narration.PINYIN` 里（似然、命中、投中、参数、重合、约掉……）。

合成之后用语音识别回听：

```bash
cd src && ../.venv/bin/python check.py      # 每句送进 qwen3-asr-flash，和配音文字对照，按字错误率列出可疑的句子
```

当前 84 句平均字错误率约 1.7%，列出的差异都是同音字或识别模型偏向常见词：先验 / 鲜艳（拼音相同）、似然 / 自然（念法已用 PINYIN 固定为 sì rán）、后验 / 后宴。

## 制作方式

- **画面**：[Manim Community](https://www.manim.community/) 0.22，公式用 xelatex + xeCJK。深色背景（径向渐变、淡网格、星点）按渲染分辨率生成一次，作为相机的背景图；“霓虹”是在线条和文字下面叠几层更粗、更透明的同色描边（`common.glow`）。后验地形图是把网格上算出的未归一化后验着色成图片，Metropolis 的每一步都来自 `data.metropolis()`。
- **对时**：场景里每句旁白写成 `with self.say("键") as d:`，动画按配音时长安排，句子念完才进入下一步；渲染时记录每句在场景里的起点，合成时据此铺配音和字幕。
- **声音**：配音之外有一层很轻的小调铺底和弦和八分音符脉动，说话时自动压低；标题出现时有一声上扬噪声加低频冲击；整片两遍 loudnorm 到 −16 LUFS。

## 生成

在 Ubuntu 24.04 上：

```bash
cd bayes-video
bash build.sh                  # 安装依赖、合成配音、渲染 1080p、合成成片 → output/bayes.mp4
JOBS=4 bash build.sh           # 4 个场景并行渲染
PREVIEW=1 bash build.sh        # 不调配音接口，按字数估计时长，出 540p 无人声预览（右上角标“未配音预览”）
```

只改了某一段时，可以单独渲染再合成：

```bash
cd src
PYTHON=../.venv/bin/python ./render.sh s3_parameter.py Shots hd
../.venv/bin/python assemble.py hd
../.venv/bin/python sheet.py Shots hd    # 每句旁白结尾的画面拼成缩略图，检查构图
```
