# 设计指南：把内容变成好的动态视觉

Motif 的设计系统负责「怎么画」。这份指南帮你做好「画什么」——这是决定作品质量的部分。

## 1. 叙事结构

好的动态作品是一条清晰的线，不是一页页的资料。先写出一句话主旨，再按下面的骨架组织：

| 场合 | 推荐骨架 | 场景数 |
| --- | --- | --- |
| 产品发布 / 宣传片 | 钩子（痛点或大数字）→ 产品是什么 → 3 个核心能力 → 证据（数据/客户）→ 号召 | 7–10 |
| 年度/季度汇报 | 封面 → 一句话总结 + 关键数字 → 分章节（每章：结论标题 + 一个图表）→ 下一步计划 → 结尾 | 8–14 |
| 融资路演 | 问题 → 方案 → 市场规模 → 商业模式 → 增长 → 竞争 → 团队 → 融资计划 | 9–12 |
| 知识讲解 / 课程 | 提出问题 → 直觉 → 定义/公式 → 推导或演示 → 例子 → 应用 → 小结 | 6–10 |
| 短视频（9:16） | 3 秒钩子（巨字/大数字）→ 2–3 个要点（每个一屏）→ 一个数据 → 行动号召 | 5–8 |
| 调研报告 | 核心发现 → 分发现（数据图表）→ 原因 → 建议 → 金句收尾 | 7–12 |

**标题写结论。** 「华南增长最快，同比 +71%」优于「区域表现」。观众只看标题也应该能懂整件事。

## 2. 内容 → 组件

| 你手里的内容 | 用这个 | 要点 |
| --- | --- | --- |
| 1 个关键数字 | `stat`（可加 `delta`、`trend` 迷你折线、`ring` 环形进度） | 数字越大越震撼，配一句短标签 |
| 2–4 个并列数字 | `stats` | 单位写在 `suffix`，不要写进 value |
| 随时间变化 | `chart` `line` / `area`（多期）或 `bar`（≤ 8 期） | 用 `highlight` 点出最新一期，`annotate` 说明拐点 |

| 转化 / 漏斗 | `chart` `funnel` | |

## 3. 版式与节奏

- `auto` 版式在大多数情况下是对的：标题 + 视觉 → 左右分栏或聚焦；标题 + 多个同类 → 网格；只有标题 → 封面/章节页。
- 想要强调某个视觉，用 `focus`；想要冲击力，用 `full`（视觉铺满，标题叠加）。
- **色调节奏**：大部分场景用 `base`；章节页、关键数字、金句用 `inverse` 或 `accent`，像音乐里的重音。不要连续使用。
- **时长**：保持 `duration: "auto"`——Motif 根据动画与阅读量计算。要配合旁白或音乐卡点时再固定秒数。
- **能量 energy**：0.3 沉稳（年报、教育）、0.6 标准、0.85 活力（短视频、发布会）。

## 4. 主题选择

| 主题 | 适合 |
| --- | --- |
| `aurora` 极光 | 科技、AI、产品发布、路演（深色、辉光、玻璃质感） |
| `editorial` 报刊 | 年报、调研、深度内容、故事化叙述（暖纸色、衬线标题） |
| `swiss` 瑞士 | 观点表达、品牌、宣言（网格、巨字、红黑） |
| `blueprint` 蓝图 | 技术架构、工程、科学原理 |
| `lumen` 数理 | 数学、物理、科学讲解（深色、粉笔感高亮） |
| `ink` 水墨 | 文化、历史、节日、品牌故事（宣纸、书法） |
| `pop` 波普 | 短视频、营销、活动、年轻品牌 |
| `corporate` 商务 | 工作汇报、方案、培训 |
| `noir` 暗场 | 电影感开场、预告、品牌大片 |
| `meadow` 青野 | 课程、科普、健康、亲和的教育内容 |

品牌色用 `set_theme` 的 `accent` 覆盖，不要逐个改块的颜色。

## 5. 画幅

- 16:9：视频、演示、发布会。
- 9:16：抖音/视频号/Reels。字要更大更少，每屏一个信息点；同一文档切换画幅会自动重排。
- 1:1 / 4:5：社交信息流。
- 21:9：电影感开场。

## 6. 动画的克制

动画服务于理解：图表按「坐标轴 → 数据 → 标签 → 注释」生长，列表逐条出现，数字滚动到位——这些主题已经做好了。你要做的通常只有：

- 想让某个结论「砸」下来：该块 `motion: {"enter": "slam"}`；
- 想让两个场景之间的同一元素连续变化：两个块设相同 `key`，后一场景 `transition: "morph"`；
- 想让某个元素持续吸引注意：`motion: {"emphasis": "pulse"}`（每场景最多一个）。
