# 数学竞赛题难度评估

## 固定估计对象

**评价对象始终是人类选手，不是AI。** 默认以学过微积分／数学分析基础、基础线性代数，接触过初等数论和组合常见方法的本科竞赛学生为参照；未见本题或同构解答，不默认具备百科式定理记忆。遇到其他课程，报告额外知识门槛；不得反过来把题目需要的全部知识都写进默认画像。

默认估计在限时、独立、无提示，仅用纸笔，不用计算器／Python／CAS／网络搜索时完成解答的困难；先区分独立解题、提示后补全、读懂和验证四类任务，完整证明与只给答案分开。必读 [人类视角检查](references/human-perspective.md)（含计算规模、工具和搜索检查）与 [人机差异证据](references/human-ai-evidence.md)。九项检查是有研究依据的工作程序，不是已验证的加权量表。

默认 CMC 指全国大学生数学竞赛；保留届次、实际考试年份、数学／非数学、A／B、初赛／决赛及年级。若语境指加拿大等其他 CMC，先澄清。IMC 指 International Mathematics Competition for University Students。

个人难度与赛事参照分开：缺少用户相应知识和做题记录，不预测个人成功率。只要求评估时，不展示关键构造、变换、答案及解题步骤。

## 每次执行

以下为实际题目定位流程；只解释评估原则、审查AI判断依据或做工具条件诊断时，按相关规则回答，不强求赛事锚题或档位。

1. 首次读取 [方法](references/method.md)、[赛事口径](references/contests.md)、必读的 [固定1–10等级表](references/rating-scale.md) 和 [输出规范](references/output-contract.md)。论文及采用／不采用的内容见 [研究依据](references/research.md)。
2. 检查题面、量词、参数范围和图片识别。分开模型认错清晰符号、原题图文质量问题，以及人类理解抽象表述／复杂条件的真实困难，最后一项必须计入难度。缺条件、错误命题、开放问题不能强塞最高档；给条件性评价，必要时询问。多问问题先分问，再评价整题，考虑前问提示和共享工作。
3. 不得以题号、原卷分值、赛事声望及已有标签代替内容判断，按human-perspective.md检查理解表征、知识检索、方法发现、策略控制、子目标协调、手工执行、证明闭合、元认知与考试条件。区分“学过／能想起／能识别适用处／能完整应用”，核查目标背景内的可达路线；冷门捷径须另查基础路线或现场重建负担。只提炼最相关的两三项瓶颈，不设机械权重。排除模型特有影响：记住短解不算人类发现，看图或算术失败不证明人类题难，token和重试次数不等于时间。读过解答后须检查后见偏差；未解出也不自动判极难。
   必查计算规模与允许工具：Python代算、枚举、CAS化简和网络找到的捷径不能让无工具人类的负担消失；记录评估者实际工具／外部提示。模型算不动时调查原因：真实规模大可支持手算路线不可行，但低效路线失败不证明所有路线不可行。查人类可发现的简化，并把发现成本与剩余手算量同时计入。
4. 用 `python3 scripts/lookup.py --topic 分析 --limit 8 --hide-stats` 或 `--id IMC-2024-P8 --hide-stats` 检索 [锚题库](references/anchors.json)。先记录内容比较依据，检索时用hide-stats减少标签干扰；固定等级表已公开，不声称统计盲评。选 3–5 道背景、逻辑结构接近而难度分散的题，尽量包含易、近、难参照。标签只辅助检索，不证明相似。
5. 阅读锚题摘要及核验笔记，核对支撑比较的关键假设。摘要不是完整题面，不能据简写补猜次数、量词、定义域、可用提示或分问条件；记录不全或替代解法不清时，打开所附原卷／解答。链接失效则标未核验并换锚。没有合适参照时扩充查找，仍不足就说明，不编造题号。摘要索引不等于完整题库。
6. 在相同背景和完成标准下，逐对判断“更易／相近／更难／不可比”，给简短可检查的理由。先写具体比较依据，再去掉 `--hide-stats` 按 ID 获取详细历史分数辅助解释，不能声称此前没有接触过固定尺度数据。对临界题交换 A/B 顺序复核。重要、分歧大或批量任务请独立 Agent 复评，只给匿名题干和统一画像，隐藏首评的新题判断与分数；固定等级表允许使用，不称完全统计盲评。Agent 一致不等于人类实测。
7. 按固定rating-scale v1.1逐题给1–10整数主分、等级和合理范围，说明相对固定真题的位置。知识、发现、计算等是评分依据，不能取代分数。证据少先补查，再给有依据的低置信暂定分及宽范围；只有题面错误、严重缺失或开放性未明等可暂缓。不同赛事满分率不直接等值，模型主观形容词不机械转成分数。

## 默认回答

严格执行rating-scale.md与output-contract.md。用户需要一把固定尺和最终分数。

- 单题先给主分、等级和范围，再说与固定真题的关系、主要人类负担及证据限制；最后重复明确评分行。通常200–500字，证据需要时加长。
- 整卷逐题列“题号｜主分与等级｜合理范围｜参照与理由｜把握”，结尾附紧凑评分清单。每题都须给分，不用末尾几个共同锚点代替逐题比较。
- 首次使用分数时展示跨年跨赛固定等级表或相关相邻行，解释代表题的内容与原题历史数据；用户不必认识题号才能读懂。以后保持v1.1同一参照，不逐次换尺。
- 原则上每题展示两个具体参照关系；证据稀疏时仍给暂定主分，但扩大范围并标低把握。原题可直接以自身为主；P10解答保留项、2023P8评级分歧项及课程条件参照按配置处理，不把它们混入默认固定标尺。
- 冷门知识的通常背景主分与已熟练掌握后的条件分分开；不以超纲代替分数、不据高级名词自动给10。
- CMC参考题及其他题集的难度排序按已评主分升序，同分并列，范围重叠保留不确定性；原题编号和原卷满分单独保留。不得假设原卷由易到难，也不得把卷面12分题直接映射成更高难度。用 `python3 scripts/lookup.py --ranked --contest CMC` 查看当前已处理题的无剧透难度序；这不是整卷或全部CMC的官方排名。额外课程条件题另列。
- 任务、提示、工具条件始终注明；短答不照搬证明赛实测成绩。全卷均摊时间不是逐题硬限，相对容易不等于用户应该会做。
- 不剧透关键方法，不造个人成功率，不把整数参考分包装成官方评级或统计预测。原则咨询不强制给题目分。

优先内容可比的已评分真题。IMC多个年份、Putnam多个年份与CMC均可作直接内容参照；不得总把IMC2025当唯一主参照、把其他赛事只留在后台。通常一组3–5题尽量跨至少两个年份；内容适合时跨赛事，不为凑赛事拉入不相关题。输出等级总表必须覆盖三赛与多个年份，具体单题仍以可比性优先。题号显示遵循contests.md，IMC注明第几天与当天题序，Putnam保留场次，CMC保留组别。无需为普通评估创建文件。

## 数据与工具

- `references/rating-scale.json`：固定v1.1评分点、跨年跨赛已评分参照及条件参照；`rating-scale.md`为给用户解释的表与评分规则。
- `references/anchors.json`：真题索引、背景、瓶颈和来源；解释性特征是本技能整理的判断，不是主办方难度标签。
- `references/imc_statistics_2023_2025.json`：官方榜单计算的 30 题聚合统计，保留空白及分母。
- `references/putnam_score_data.json`：官方报告中 36 题、总分前列子群体的频数，不是全体数据。
- `scripts/lookup.py`：只读检索；派生同年五档，分开显示满分率排序与均分排序。完成内容比较后用 `--rating-scale` 生成固定评分卡；`--contest IMC --scale-year 2025` 仅为年内历史辅助卡。不能把只有统计的题自动当内容锚。
- `scripts/rank_pairs.py`：仅批量且已有实际记录的成对判断时使用；输入和限制见 method.md。不创造人类校准，禁止伪造比较输入。
- 数据快照为 2026-09-27；这是初始参考库，不是最新全量题库、训练好的预测模型或经过大规模人类验证的量表。

## 增量校准

真实做题记录可建立个人参照：保存背景、是否见过、提示、时间预算、实际得分和评分标准；单次失手不改公共难度。新增锚题带可靠来源与证据类型。用户未要求保存时，不把本次评估写入技能；保存修改使用 skill-creator。

按 method.md 的留出方案验证升级。没有真人作答或独立专家评审，不声称预测准确率已验证。
