# 以人类选手为评价对象

## 核心约束

**AI的知识覆盖、模式识别速度、记忆到的标准答案和搜索能力不是人类考场能力。** 目标是估计指定背景的真人首次面对题目时，从有限知识库里独立找到并完成方法的难度。不能只在提示词中写“扮演学生”，然后仍用模型最熟的捷径打分。

默认背景只包括微积分／数学分析基础、基础线性代数、初等数论和组合常见方法；本科课程中的某个知识点不等于多数选手已熟练掌握。具体赛事／组别课程范围可调整背景，但范围内仍需辨别常见、偏门和专门训练。固定画像在先，读题后不能悄悄扩充画像来让题变简单。

## 知识可达性检查

对决定性的每个定理、定义、技巧或现成公式，标记以下来源性质。此分类是工作检查表，不是经统计验证的数字量表。

| 类型 | 主评价如何处理 |
|---|---|
| 课程核心且题面直接提示 | 可以视为已有工具，但仍核查推导与应用细节。 |
| 常见竞赛工具，但需要自行发现关联 | 区分会用该工具与想到本题使用它；计入识别和选择困难。 |
| 冷门定理、特殊定义、现成公式、训练过才熟悉的套路 | 默认不在选手可随时调用的知识中。主评价检查自然基础路线或现场重建关键结论的成本。 |
| 超出目标课程／训练范围 | 单独报告知识缺口；可附“学过这门课后”的条件难度，不据高级名词直接判极难。 |

“常见”的依据优先是当年课程范围、可靠教材的核心章节、实际训练材料和真实参赛表现。**AI熟悉程度、搜索结果数、条目有维基页面不能作为常见性证据。** 不确定时保留两种背景条件，不擅称“大家都知道”。

至少区分四个环节：接触过概念；能在没有提示时回忆；能从当前包装认出相关结构；能检验条件并把论证完成。知道定义并不代表能识别隐藏的定义；题目与某经典定理同构也不代表人类能立即认出。

## 两条路线与主次顺序

1. 先检查目标选手通常拥有的工具下是否存在合理可发现的解法；评价关键转折、容易停滞处及完成证明的负担。提供可检查的概要，不输出仿装真实内部思维链。
2. 若模型找到的短解调用偏门结论，检查不用该结论是否仍有自然短解。若有，按该基础路线评价；若没有，知识识别／现场重建本身就是主困难，不得把引用后的一行证明当成主难度。
3. 若用户已明确学过并练熟该工具，可另外给其个人条件评价。若原题把定义或关键引理直接给出，则按实际提供的脚手架降减相应负担；不能给没提示的原题同样待遇。
4. 主结论是通常背景下首次作答的难度；副结论才是“预先知道对应结果后，执行较容易”。不把后者偷换成题目本身简单。

冷门并不自动很难：若题面充分引导或基础推导自然，仍可较易；常规定理也不自动简单：隐藏适用条件、反向构造、选择恰当表示可能很难。把知识门槛与洞察困难分别讲清。

## 禁止的降级理由

- “这是某某定理的直接推论，所以简单”，却未检查该定理对目标选手是否常见。
- “只是定义题”，却需要先识别题面背后的冷门结构或陌生定义。
- “答案只有三行／我一眼就看出／模型全部做对”，所以人类也应容易。
- 在看过标准解答后，倒推关键选择对考生显而易见。
- 把独立Agent都认出熟题当作真人容易的证据。

对于这些情况，改为报告人类可达性与具体真题对比。如果无法核验自然路线，给暂定范围并说明不确定原因，不编造学生成功率。

## 与数据及研究的关系

真实考生成绩是校正模型视角的重要证据，但仍受群体和考试条件影响。假设有高满分率却需冷门工具，先找更自然的替代解法、题面提示或真实课程差异；低满分率却有熟悉短解，先查关键发现是否隐蔽、细节或时间分配是否重，不单凭自己感觉推翻数据。

MOHS作者明确区分接触与熟练，并对足以把题目直接消掉的专门结论通常不作已知假设（如组合零点定理、钩长公式）；这里采用这一知识边界原则，不照搬其等级。Li等的Difficulty_Alignment在其测试的零样本熟练度提示设置中发现，要求模型模拟不同水平学生不能保证与真人对齐；这不等于否定所有用真人数据训练或提供错误示例的方法。本技能采用显式知识清单、原题作答数据和内容比较约束，不能声称这已完全复现人类认知。

## 系统检查人机差异

知识覆盖只是一个维度。使用 [人机差异证据表](human-ai-evidence.md)，逐项检查以下可能影响评级的机制；无关项可略过。表中是评价程序，不是固定加分项，也不声称AI和人类总有同一方向的能力差。

| 环节 | 面向人类要评什么 | 排除的模型替代指标 |
|---|---|---|
| 理解与建立表征 | 陌生记号、嵌套量词、长条件、隐含关系、复杂图形及自然语言转数学的真实门槛，均可构成人类难度。 | AI把清楚的符号认错不自动说明人也读不懂；若原图本身模糊、印刷或表述有问题，单列题面质量／阅读负担，不能冒充数学洞察难度。 |
| 知识检索与迁移 | 有限知识中能否想起相关工具、识别等价结构；熟题、改编题与真正新构造分别处理。 | 模型记得原题、见到定理名就命中；模型改字母／数字后变差也不自动代表人类变难。 |
| 方法发现与搜索 | 自然起点有多明显，是否需要无提示地换表征、另造辅助对象或提出中间命题；是否存在多条可达路线。 | 只评标准解答的执行长度，或把多个Agent并行找到的路线当单个人可立即发现。 |
| 策略控制 | 选择哪条路线、何时发现方法无效、切换后能否利用已有成果；是否有耗时而看似有希望的常规尝试。 | 模型反复生成次数、搜索树节点、重试成本不直接等于人的犹豫时间；不编造真人失败过程。 |
| 子目标协调与记忆 | 同时维护多少相互依赖的条件、边界情形、符号和中间结论；是否可借纸笔、图示或熟悉结构分块。 | 模型上下文长度、token数不是人的工作记忆容量；步骤很多不必然高负担，结构不熟也不能当作无成本。 |
| 手工执行 | 真实纸笔运算量、数字规模、展开长度、分支数量、精度、索引管理与易错点；没有可达简化时，大量机械计算也是主要难度。 | Python／CAS／枚举能力不属于无计算器选手；AI单次算错不等于负担大，但已核验的巨大计算规模不能作为“模型问题”忽略。 |
| 证明闭合与检查 | 从猜想／答案到必要充分性、全称量词、存在构造、等号和退化情况的距离；哪些缺口不容易察觉。 | 流畅文本、正确最终数值、模型自称严谨不代表证明完成；验证现成答案不等于发现证明。 |
| 元认知与信心 | 学生是否容易误以为已完成，能否用可用方法发现错误；有真人记录才谈实际误判率。 | 模型自报信心、自我纠错成功或多模型一致不能作为真人成功概率。 |
| 时间、工具与试卷条件 | 单题独立作答和整卷争取分数不同；读题、探索、书写、复核都耗时间；前题消耗和提示改变任务。 | 生成速度、墙钟时间、token或pass@k不换算成人类分钟；不凭空设焦虑、疲劳或情绪加分。 |

**只报告主导困难的两三项**，不把九行机械变成九个分数。对每项判断尽量给题目结构或可比真题支持，来源不足写不确定。研究中的模型快照、学生年龄和题型必须保留：儿童算术结果不能直接成为本科证明题的权重，旧模型弱点不能宣称是当前所有模型的固定弱点。

## 执行顺序与审查记录

先核实输入完整性，再固定真人画像、允许工具和任务类型：独立解题、提示后补全、读懂或验证。四类任务不可互相替代；检查容易不推出发现容易，也不预设固定的难度次序。然后检查上述环节，用基础可达路线校正模型熟题捷径；先记录内容比较依据，再调取详细历史分数辅助解释。固定等级表已公开，不能声称统计盲评。保留简短审查记录：`target_background`、`task_mode`、`hints_and_tools`、`input_reliability`、`recognition_risk`、`knowledge_access`、`main_human_bottlenecks`、`model_specific_artifacts_excluded`、`anchor_comparisons`、`uncertainty`。这些是可检查的判断摘要，不要求或展示内部思考链。

必要时对等价改写作稳健性检查：先验证数学任务确实等价，且没有增删暗示、图形或特殊数值。若只改字母而评级大变，应审查模型偏差；若改写隐藏关键结构，真人发现难度确可变化，不能强制同级。

这里“只改字母”例如把同一道题的变量x一致改成t，不改任何条件。它不包括把熟悉记号换成陌生记号、把结构明显的公式改写成隐蔽叙述、增加量词嵌套、删除图形提示。后几种改动即使数学等价，也可能让人更难读懂或想到方法。

## 计算负担与工具差异：必须单独核查

默认目标选手用纸笔，不用计算器、Python、CAS或网络搜索。评估者可用这些工具核验，但不能把工具代劳的部分从人类负担中删去。记录实际使用：`evaluator_tools_used`与`solver_tools_allowed`，并说明工具是在算数、试例、搜索、发现结构还是验证证明。

1. **先核对所求的形式。** 要完整十进制数字、精确闭式、近似值还是存在性证明？写一个和式、程序或浮点近似不一定满足题目要求；有限试例也不能替代全称证明。
2. **列出手算任务的规模。** 看乘除次数与位数、多项式展开项数、需检查的情况数、递推深度、精度和人工核验负担。可给有依据的数量或数量级，不把它直接换算成未经真人校准的分钟数。
3. **同时查自然的结构简化。** 对称、配对、消去、递推、模运算或其他目标背景内的路线能否避免蛮力？必须评价“能想到简化”的成本，不能搜索到巧解后就把它当显然。例如从1加到一百万的逐项程序很长，但这不证明该求和题手算很难。
4. **工具完成不等于人类可完成。** 仅找到需大规模枚举／数值优化／CAS的路线时，说明该路线在无工具考场不现实，且当前没有核验可达的纸笔路线；不能给低难度。也不能仅因算力大就称数学洞察最难：可能是执行繁重或题目不适合该考试时限。
5. **“AI也算不动”应调查，不应丢弃或直接定级。** 若原因是已核验的巨大执行规模，该路线对手算者通常更不现实，应成为重要证据。若原因是代码错误、选了低效算法、没发现简化或模型读题错误，则不能推出题目对所有人都更难。对“当前路线不可行”有证据，不等于已证明“所有路线不可行”。
6. **搜索收益必须扣回。** 网络找到的定理、关键引理、标准解答、数列识别或特殊积分公式是评估者的外部信息，不是闭卷选手题面自带的提示。记录`external_hint_exposure`；可以据此核验答案，但主评价必须重新检查无提示发现、知识回忆与证明补全。无法判断发现门槛时降置信；不能声称看过答案后已恢复真正盲评。
7. **工具条件变化就分条件评价。** 用户允许计算器、编程或开卷搜索时，按实际条件另评建模、算法设计、检索选择与验证负担。无工具、允许计算器、允许Python和允许上网不是同一条件；不要预设所有AI都能用工具，也不要预设所有人都不能用。

计算负担、题意理解都属于主评维度。排除的是把模型自身表现当成直接分数，不是排除这些真实困难。

## 独立复核的额外问题

复核者先不看首评，只拿题目、固定人群、实际允许的知识／提示；检查：有没有把偏门结果当基本常识？低评级是否仅来自已知公式？隐藏定义的识别是否被省略？未见该结果的人有没有自然路线？主评与“知道以后”的条件评是否颠倒？有没有把读懂／补全／验证当独立发现，把模型感知／计算问题当真人数学困难，或用token等指标代替真人时间？
