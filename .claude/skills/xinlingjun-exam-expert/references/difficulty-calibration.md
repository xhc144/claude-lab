# 人类难度与教学校准

把人类首次见题的发现负担用于讲题、诊断、选题和命题。仅在实际评级任务中输出固定分数；普通“怎么做”或“出一道题”不自动附评分表、比赛锚点和来源清单。

## 两种调用范围

| 情形 | 执行内容 |
| --- | --- |
| 讲概念、解题、提示、批改、普通选题或“难一点” | 用下列人类视角确定卡点、提示大小、前置与手算负担；不宣称完成正式评级 |
| 几分难度、竞赛水平对照、两题比较、排序、整卷评价 | 启动完整固定尺v1.1流程，逐题给整数主分、等级、范围、真题比较和证据把握 |
| “按7/10出题”或与某真题同档的命题 | 把目标作为设计约束，先解完并独立复核，再正式校准；只要题面时将评级依据与解法保留内部 |
| 仅讨论评级原则或质疑AI判断 | 回答判断依据与人机差异，不为此强造一道题的分数 |

## 所有教学与命题的人类视角

固定目标背景、允许工具、是否见过题、是否已有提示和完成要求。不能读到冷门工具后悄悄把它加入“学生都会”的先修。公共参考难度与该用户当前适配分开；用户已掌握的额外工具可另给条件判断，不擅自预测个人成功率。

至少区分学过、能无提示想起、能从当前包装识别、能检验条件并完成。独立解题、提示后补全、读懂与验证是不同任务。给出关键引理或结构名以后做出来，不能据此认定用户已能独立发现；迁移用未给过答案的变式检验。

人类视角同时决定教学动作：知识缺口先直接解释最小前置，表示或发现困难给有理由的提示，连接受阻可示范局部，已有独立表现时减少支架。完成提示后的步骤只记为对应支持下的完成，不升级为无提示识别；公共题目难度与个人当前需要的讲解分别判断。

只提炼当前最主导的两三种障碍：

- 理解与表征：哪些对象、量词、隐含关系或换写方式难以看清。
- 知识可达性与方法发现：目标学生如何触发观察；冷门短解之外是否有自然基础路线。
- 策略与子目标：怎样判断当前路线够不够，局部收获如何接到剩余目标。
- 手算执行：展开规模、位数、分类、递推深度、精度和人工检查负担。
- 证明闭合：必要充分性、全称、存在/唯一、取等、退化、交换极限与误差控制。

不将这些条目加权相加，也不机械展示全部。AI记住标准答案、解答短、秒解、工具算完、重复尝试次数或多个Agent同意都不能直接定真人难度。核验可使用代码、CAS或搜索，但闭卷纸笔负担不会因此消失；外部找到的关键引理不算题面自带。反过来，低效路线或模型读错失败也不能证明所有人类路线都难。

教师的2—3次结构观察与“1.3倍”是本用户的设计要求，不是评级公式；不能据此给真实单板块题设难度上限。检查教师风格、题目数学正确性与人类难度是不同工作。

## 正式固定尺流程

这些文本和数据已随本技能保存，不依赖两个上传ZIP、临时路径或其他技能是否安装。正式评级首次读取 `difficulty/` 下的 `method.md`、`human-perspective.md`、`human-ai-evidence.md`、`contests.md`、`rating-scale.md` 和 `output-contract.md`；研究范围见 `research.md`。当前会话完整已读且未变化的资料可复用。所有入口也直接列在主 `SKILL.md`。

1. 核对完整题面、量词、参数和分问，先固定背景与任务。固定尺默认基础分析、线代、初等数论及常见组合方法的本科竞赛生首次独立纸笔；用户指定其他背景时明确条件，不移动已有锚题分值。
2. 独立核验可达路线、主要发现、执行量和证明负担。只要求评价时，不输出关键构造、方法、答案或步骤。
3. 用下面的脚本查3—5道背景、结构接近且难度分散的参照。标签仅帮助检索；先比较内容，再查看详细历史成绩。记录看过解答或外部提示的影响，不声称真正盲评。
4. 阅读锚题摘要与核验状态；摘要不是完整题面，条件不足时读可靠原卷/解答，或换用能核验的参照。仅成绩索引、解答保留项、延迟评级项和额外课程条件项不能混入默认内容标尺。
5. 按同一背景与完成标准逐对比较，给具体数学负担的差异。内部参照可多，最终原则上展示两个可读真题关系；不为凑赛事使用无关题。
6. 按v1.1给1—10整数主分、等级、合理范围及证据把握。范围是判断余量，不是统计置信区间；跨赛事比例不直接等值，序数分不平均成伪精确小数。
7. 完整题面但锚点稀疏时先补查，再给有理由的暂定分、宽范围和低把握。仅题面严重缺失、错误或开放性未明等才暂停并指出阻碍。重要、分歧大或批量任务按原流程独立复评。

在本技能目录运行：

```bash
python3 scripts/query_difficulty.py --topic 分析 --limit 8 --hide-stats
python3 scripts/query_difficulty.py --id IMC-2024-P8 --hide-stats
python3 scripts/query_difficulty.py --id IMC-2024-P8
python3 scripts/query_difficulty.py --rating-scale
python3 scripts/query_difficulty.py --ranked --contest CMC
```

不能执行脚本时直接读取 `difficulty/anchors.json`、`difficulty/rating-scale.json` 和相关成绩数据；不能只凭“中等”改写成5分。正式评分按原输出规范收束，每道可评价题有最终评分行，例如“最终难度：5/10（III级；合理范围4—6；把握中，固定尺v1.1）”；该例仅是格式，不预设答案。

## 数据与显示边界

固定参考尺为自定义内容尺度，不是官方评级或预测模型。IMC成绩保留全榜分母及暂定状态；Putnam仅前列总分样本，不能外推全体；CMC没有可靠全体逐题数据时不编满分率。原题成绩不成为新题或该用户成功率。

赛事参照必须写完整年份、场次/天次、题序和必要组别，给不剧透短题意，不能只丢陌生ID。首次向用户显示固定分数时解释相关等级行；后续可复用。整卷逐题评价并保留评分要求、时间和知识跨度，均摊时间不是单题硬限。评分参照不得泄露当前题的关键路线。
