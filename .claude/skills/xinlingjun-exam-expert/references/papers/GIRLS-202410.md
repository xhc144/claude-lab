## 第6题〔GIRLS-202410-Q06〕：整数特殊线性群的有限阶与上半平面稳定子

记
$$\operatorname{SL}(2,\mathbb Z)=\left\{\begin{pmatrix}a&b\\ c&d\end{pmatrix}\mid a,b,c,d\in\mathbb Z,\ ad-bc=1\right\}.$$
若存在正整数 $k$ 使得 $A^k=\begin{pmatrix}1&0\\0&1\end{pmatrix}$，则称 $A$ 为有限阶，其中满足条件的最小 $k$ 称为 $A$ 的阶。
（1）设 $A\in\operatorname{SL}(2,\mathbb Z)$，求 $A$ 的阶的所有可能值；
（2）求所有的 $z\in\mathbb C$，使得 $\operatorname{Im}z>\frac12$，且
$$\left\{\begin{pmatrix}a&b\\ c&d\end{pmatrix}\in\operatorname{SL}(2,\mathbb Z)\ \middle|\ \frac{az+b}{cz+d}=z\right\}$$
中至少有 $3$ 个元素。

| 字段 | 内容 |
| --- | --- |
| 领域 | 群论；线性代数；几何 |
| 知识点 | 特殊线性群；有限阶矩阵；整数迹；分式线性变换；稳定子 |
| 候选方法 | 候选：由有限阶约束特征值并结合整数迹分类；候选：把固定点方程化为整数系数二次方程；候选：用虚部界限制c和其他整数参数 |
| 结构性观察 | 代数阶数条件转换成谱与迹的离散限制；稳定子至少3个需注意±I恒固定 |
| 前置知识 | 二阶特征多项式；群作用与稳定子；复数虚部 |
| 考纲代码 | M1-G；M1-L |
| 范围关系 | 拓展迁移 |
| 原卷页码 | 2 |
| 转录状态 | 已目视核对 |

迁移说明：线性群与群作用在新纲；模块群上半平面固定点是专门交叉场景，不代表要求一般模形式理论。

题面注：第(1)问并未先假设A有限阶，按字面求阶可能值应区分有限阶与无限阶；题面前段仅对有限阶元素定义最小k。第(2)问阈值是严格Im z>1/2。
