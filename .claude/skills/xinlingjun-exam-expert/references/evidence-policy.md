# 证据与材料范围

## 证据身份

| 类别 | 可支持的结论 | 不可越界的结论 |
| --- | --- | --- |
| 已读官方公开原文件 | 对应招生年度规则、范围与公开通知 | 未公布的时长、分值、比例或后续变化 |
| 官方文件的用户提供副本 | 文件列明的2027选拔结构、范围、参考书与日程 | 声称已联网核验、未列明的分值时长、后续变更 |
| 媒体访谈、个人复盘、教练/培训材料 | 已核读的个人经历、公开观点、课程内容与可试验训练建议 | 全体难度/通过率、因果效果、官方评分、把旧二试当新版二试 |
| 数之谜历年整理卷 | 所给年份/月份/场次的题面、可迁移方法 | 已独立核验官方原卷、2027新考纲真题、新版必考概率 |
| 教师聊天截图 | 教师命题偏好与对该学生的阶段建议 | 官方考试规定、所有考生的统一水平 |
| 参考教材知识点及TeX | 用户整理的教材知识节点与标注的延伸 | 教材所有内容都必考、未提供的配套目录JSON已被核对 |
| AI分类与推断 | 题型标签、候选方法、训练建议、跨板块关系 | 已完成严格解答、官方命题意图或标准答案 |

## 时间和版本

本库建立及网络研究基准日为2026-10-11。默认对象为2027招生年度。新考纲文件署日期2026-08-20，招生简章署日期2026-09-28；第一批在2026年10—11月选拔。2027首次实施新考纲是用户明确强调的分析前提，考纲亦表述“首次发布”；已核验官方发布目录与新招生正文。历年卷全部标为旧制度素材；目前没有2027新考纲已实施试题。

两份考纲PDF是字节完全相同的副本（SHA-256见材料清单），与其配套TeX只有同一信息来源，不形成三份证据。参考教材PDF与TeX为同一整理资料的两种格式。

## 资料边界

收到23份历年整理卷：一试6份、零试11份、女子场5份、CACA1份。文件夹名“4h”“3h”“2h”仅保存为历史标签；不是2027时长依据。所有大题建立稳定ID并转成完整文本题面，不把原PDF放入技能。

引用历史题可以使用“本库所收录的历年整理真题”及确切场次定位。首次涉及出处可靠性时简要交代是用户提供整理卷；不要每题重复免责声明，也不要悄悄宣称已独立核验。

题库方法栏是AI候选分析。原题存在语义缺口时保留原貌并在notes说明。对未来招生与日程事实，查最新官方通知后再给实时结论；材料中的报名截止和考试安排不随当前时间自动改写。

网络证据见 [使用说明](web-evidence-guide.md)，历史变化见 [逐年官方框架](historical-framework.md)。逐条保存已读/未读状态；官方域名转载的媒体仍按句子区分负责人立场、记者概括与第三方判断。
