三、算法怎么写？

Python
def solve(S, T, b):
n = len(b)
x = [0.0] * n
y = [0.0] * n

for i in range(n - 1, -1, -1):
u = 0.0
v = 0.0

for j in range(i + 1, n):
u += T[i][j] * x[j]
v += S[i][j] * y[j]

d = S[i][i] * T[i][i] - 1

if d == 0:
raise ValueError("矩阵不可逆，不能使用此回代算法")

x[i] = (b[i] - v - S[i][i] * u) / d
y[i] = T[i][i] * x[i] + u

return x

整个过程中，我们从来没有计算过 STST。

四、算法题中的计算量到底怎么算？

这是你更值得掌握的部分。

通常我们采用基本算术运算计数模型，把一次标量加法、减法、乘法或除法看成 O(1)O(1) 次操作。

例如：

a1b1+a2b2+⋯+anbna_1b_1+a_2b_2+\cdots+a_nb_n

需要 nn 次乘法和 n−1n-1 次加法，所以是 O(n)O(n)。

再看刚才的算法。

对于固定的 ii，我们要计算两个和：

ui=∑j=i+1ntijxj,vi=∑j=i+1nsijyj.u_i=\sum_{j=i+1}^nt_{ij}x_j,\qquad v_i=\sum_{j=i+1}^ns_{ij}y_j.

每个和包含 n−in-i 项，因此这一轮计算量为

O(n−i+1).O(n-i+1).

所以总计算量是

C(n)=∑i=1nO(n−i+1)=O(n+(n−1)+⋯+1)=O(n(n+1)2)=O(n2).\begin{aligned} C(n) &=\sum_{i=1}^n O(n-i+1)\\ &=O(n+(n-1)+\cdots+1)\\ &=O\left(\frac{n(n+1)}2\right)\\ &=\boxed{O(n^2)}. \end{aligned}

五、以后遇到类似的复杂度题，怎么思考？

我建议抓住三个原则：

  1. 不要急着构造中间矩阵。 如果后续只是用它乘一个向量，尽量直接计算所需的结果。

  2. 寻找可以重复利用的中间量。 本题的 Y=TXY=TX 就避免了反复计算同样的乘积。

  3. 把循环的计算量写成求和。 比如 ∑i=1ni=O(n2)\sum_{i=1}^n i=O(n^2)，而双层均运行 nn 次的循环则是 O(n2)O(n^2)。

另外，本题还有一个值得注意的地方：题目写的是大写的 X,BX,B。如果它们是列向量，上面的 O(n2)O(n^2) 解法成立；如果 BB 是一般的 n×nn\times n 矩阵，那么需要解 nn 个右端向量，普通方法的总复杂度是 O(n3)O(n^3)，不能直接说是 O(n2)O(n^2)。

这道题最有价值的思想可以概括为：不要显式计算复合运算的完整矩阵，而要利用辅助变量和已知结构，直接计算最终需要的量。
