    怎样保存对话

    1. 在浏览器里打开对话，先滚动到最上面，让整段对话都加载出来。
    2. 按 Ctrl+S，保存类型选 “网页，全部”（得到 .html 和同名 _files 文件夹）或 “网页，单个文件”（.mhtml）。
    3. 把 .html 文件（或整个文件夹、打包的 .zip）拖进左边的方框。只有 _files 文件夹不够：对话正文在 .html 里。

    也可以：选中聊天内容按 Ctrl+C 后点 粘贴；或导入 Markdown、ChatGPT / Claude 的数据导出（conversations.json，里面的每段对话都会列出来）。

    预览与排版

    选中列表里的对话，中间是即时预览，右边调整版面。点击预览里的公式可以在行内与行间之间切换，点击标题改级别，点击图片改大小，任何段落前都可以插入分页。PDF 标签页显示 TeX 实际排出的结果，改动后自动重新编译。

    图表与交互内容

    ChatGPT 回答里的图表、示意图、滑块等交互组件，按保存网页时的样子截取成清晰的图片放进 PDF；SVG 示意图保留为矢量图。导出的 HTML 里，公式点击即复制 TeX，HTML / SVG / JavaScript 代码可以直接运行。
