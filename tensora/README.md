# 星枢 Tensora · AI 基础设施控制台

一个把 **API 中转网关**、**模型训练平台**和 **GPU 算力控制台**合在一起的 AI 基础设施管理平台前端。纯静态、零依赖，所有数据都在浏览器里实时模拟，每个可见的按钮、开关、表单和图表都有对应的反馈。

> 演示项目：模型、厂商、团队成员与账单都是虚构的，页面不连接任何后端，也不会产生真实交易或发送邮件。数据集导入只使用文件名与大小生成模拟统计，不上传或读取文件内容，也不执行实际去重、格式校验或隐私扫描。

## 运行

```sh
cd tensora
npm start                 # http://127.0.0.1:5173/ ，源码版（ES modules，需要 HTTP 服务）
npm run build             # 生成 dist/tensora.html：CSS 与全部模块内联的单文件
```

`dist/tensora.html` 可以直接双击离线打开。字体来自 Google Fonts，离线时自动回退到系统字体。

## 设计

- 深空底色上的低分辨率 Canvas 极光光场，色相随所在区域（网关青 / 训练紫 / 算力金 / 账户绿）缓慢过渡，并随实时吞吐轻微呼吸。
- 玻璃面板跟随指针的边缘高光、滑动指示的分段控件、弹性开关与星标、加载态按钮与带进度的 Toast。
- 图表全部手写 SVG：同一张图只有一个 y 轴；两个以上系列都有图例；折线带十字准线读数，柱状图逐柱读数，焦点后可用 ← → 键移动；分类配色按色觉缺陷安全顺序固定分配，状态色只用于状态并总是配图标与文字。
- `prefers-reduced-motion` 或设置中关闭动效后，所有动画与光场流动停止，功能不变。

## 测试


## 结构

```
index.html          入口
css/app.css         设计令牌、组件、页面与响应式样式
src/main.js         启动、路由（#/page/param）、页面切换
src/core/           util（格式化、存储、随机数）、data（模拟数据）、state（全局状态与事件总线）、live（每秒一次的实时模拟）
src/ui/             shell（导航、命令面板、通知）、charts（图表组件）、overlay（弹窗、抽屉、菜单、Toast）、kit、icons、sigil（模型徽记）、aurora（背景光场）
src/pages/          10 个页面，每个导出 { mount, update? }
scripts/            build（单文件打包）、serve（静态服务）、check（静态检查）
tests/e2e/          Playwright 端到端测试
```
