音乐粒子宇宙 {VERSION} · Windows 64 位便携版
==========================================

运行
  解压整个文件夹后，双击 ParticleUniverse.exe 即可。无需安装、无需管理员权限、无需联网。
  请保持文件夹内的文件完整（exe 依赖同目录下的 dll / pak / resources）。

系统要求
  Windows 10 / 11 64 位；支持 DirectX 11 与 WebGL2 的显卡（近十年的独立显卡或核显均可）。
  笔记本双显卡：程序会请求高性能显卡；若仍使用核显，可在
  「设置 > 系统 > 屏幕 > 显示卡」中把 ParticleUniverse.exe 设为“高性能”。

快速上手
  · 拖入音频文件，或点击「导入本地音乐」（MP3 / FLAC / WAV / OGG / M4A / AAC）。
  · 没有音乐文件时，可以先播放「内置演示曲」。
  · 「捕获系统声音」可以可视化任何播放器正在播放的声音。
  · 空格 播放/暂停 · 1–8 切换场景 · C 自动运镜 · F 全屏 · H 隐藏界面 · X 导出视频 · ? 全部快捷键

视频导出
  点击底栏的胶片图标（或按 X）。逐帧离线渲染，支持 720p / 1080p / 2K / 4K / 竖屏，
  30 或 60 fps，MP4 (H.264) 或 WebM (VP9)。

数据位置
  设置与播放列表保存在 %APPDATA%\ParticleUniverse。截图保存在「图片\音乐粒子宇宙」。

说明
  本程序未进行代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”，
  可点击「更多信息 → 仍要运行」。源代码见 https://github.com/xhc144/claude-lab/tree/main/particle-universe
