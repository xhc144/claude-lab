# 输入日报 · 使用说明

平时照常用微信输入法打字、说话就行，**不用到任何地方专门输入**。微信输入法会把你按回车时输入框里的文字记进它自己的日志，这里的脚本每晚去读这份日志，整理好后交给 DeepSeek 写日报。

## 第一次用（只做一次）
1. 去 <https://platform.deepseek.com/api_keys> 创建一个 API key。
2. 用记事本打开 `配置.txt`，把 key 粘贴在 `DEEPSEEK_API_KEY=` 后面，保存。
3. 双击 `立即生成日报.bat`：会把 9 月 21 日以来所有的日报一次补齐（33 天左右，要跑十几二十分钟）。

之后不用管它：**每天 23:30 自动运行**；那个时间电脑没开，下次开机会补跑。哪天没跑成，下次也会自动补上。

## 文件在哪
| 文件 | 是什么 |
|---|---|
| `日报/` | 每天一篇日报，文件名是日期 |
| `输入记录/` | 每天整理好的输入原文（去重、打码后），日报就是根据它写的 |
| `运行日志.txt` | 每次自动运行的情况，出问题先看这里 |
| `配置.txt` | DeepSeek key、模型、不记录的软件 |
| `立即生成日报.bat` | 想马上看今天的日报就双击它 |

## 看板
点**桌面或开始菜单里的「输入日报」**就会打开软件窗口（本机网页，只有这台电脑能访问）。关掉窗口，后台一分钟后自己退出；DeepSeek 正在写的话，会等写完再退。

软件本体在 `E:\项目\03_效率工具\输入日报`，日报、输入记录、配置都在这个文件夹里。要挪位置的话，挪完得重新建快捷方式、改每晚的自动任务，让 AI 帮你弄就行。

- **一键整理**：右上角「一键整理所有没写的日报（DeepSeek）」，把还没有日报的日子全部交给 DeepSeek，进度条显示写到第几天。Claude 写好的不会被覆盖。
- **单天重写**：在下面的日报列表里点某天，再点「让 DeepSeek 重写这天」。
- **图表**：每天输入量（段数和字数）、用在哪些软件、作息热力图（每天每小时打了多少）、一天中的时段分布、烦躁信号（抱怨骂人的词出现次数）、常出现的事、待办汇总（可以勾掉，只记在这个浏览器里）。

## 隐私保护
- **不记录的软件**：在 `配置.txt` 里列出的软件（默认是各种密码管理器），里面打的字整条丢掉，不会发给 DeepSeek。
- **自动打码**：各种 API 密钥和令牌、`密码是…`/`password=…`、验证码、身份证号、银行卡号会被替换成 `[已隐藏…]`，手机号只留前三后四，网址后面的参数整段去掉。整理记录时打一次，发给 DeepSeek 前再打一次，日报写回来后又打一次。
- **不留原始日志的副本**。
- 日报里如果提醒你"某时某处发过密钥"，建议去对应平台把那个密钥换掉。

还要注意：
- 发给 DeepSeek 的是**打码后的输入记录**，会经过 DeepSeek 的服务器。
- 微信输入法自己的日志（`AppData\LocalLow\Tencent\WeType\context_capture\`）仍然是明文，这是输入法本身的行为，这里改不了。
- 打码是按规则认的，不能保证百分之百认全，特别敏感的东西尽量别在电脑上用输入法打。

## 暂停 / 关掉
- 暂停：开始菜单搜「任务计划程序」，找到 **输入日报-每晚生成**，右键「禁用」。
- 彻底删除：同一个地方右键「删除」，再把这个文件夹删掉。

## 局限
- 只看得到你发出去的话，看不到对方的回复。
- 分不出哪句是打字、哪句是语音。
- 微信里的输入记得偏少。
- 最早只能追溯到 2026-09-21，输入法的日志就是从那天开始的。
- 输入法以后更新，日志的格式或位置可能会变，到时候脚本会在 `运行日志.txt` 里提示找不到日志。
