# 倒悬之海 · The Sea Above

一部约 71 秒的程序化三维短片。主题：一个不可能存在、却令人向往的世界 —— 海洋悬在天上，水往高处流，世界会卷起来，月亮是一滴水。

**成片**：`out/the_sea_above.mp4`（1920×1080，24 fps，2.35:1 画幅，立体声）。成片已从原影片分支整合，可在 [项目主页](https://xhc144.github.io/claude-lab/films/sea-above/) 在线播放；在本目录运行 `./make_film.sh` 可从源码重新生成。

所有画面都由本目录里的着色器逐像素计算出来，所有声音都由 `audio/` 里的合成器生成。没有使用任何外部模型、贴图、HDRI、音色或录音。

## 技术

这台机器只有 4 个 CPU 核、没有 GPU，Blender Cycles 渲一帧空场景都要 20 秒，所以整部片子用 **GLSL 光线步进（ray marching）着色器**完成，借助 Mesa llvmpipe（软件 OpenGL，自动向量化到 AVX2）在 CPU 上运行。一帧 1920×816 的画面需要 3–20 秒。

- **几何**：全部是有向距离场（SDF）。钙华梯田是对地形高度做阶梯化得到的（池沿、水池、垂挂的钙华帘），水柱与悬海用平滑并集连成"液桥"；夜晚的城市由带拱廊的塔、螺旋楼梯、拱桥和朝不同方向的阶梯组成；座头鲸是一个旋转体加上鳍、尾叶、喉褶和游动时的波动
- **不可能的几何**：世界卷起是对空间坐标做圆柱展开（把弯曲空间映射回平面再求距离场）；月亮是一颗水滴，折射光线会直接进入另一个世界的渲染函数
- **光照与材质**：低角度太阳、悬海透下的绿松石色天光与焦散、按高度积分的大气雾、柔和阴影与 AO、菲涅尔反射与折射（水池、水柱、露珠内部两次折射与全反射）、草叶的透光与绒毛高光、水下的上涌光柱、夜晚的灯笼光晕（沿射线积分）
- **采样**：每帧 4 个子样本，各自带不同的像素抖动和快门时间（180° 快门的运动模糊）；微距镜头的景深由基于深度的 bokeh 散景后处理完成
- **精度**：微距场景里的草叶和露珠只有几毫米，在世界坐标（约 100 m）下 float32 精度不够，所以在以草根为原点的局部坐标系中求交
- **性能**：地形的大尺度噪声预先烘焙成浮点纹理（`engine/bake.py`），渲染快了约 7 倍
- **后期**：多尺度辉光、AgX 色调映射、分镜头调色、暗角、轻微色散、胶片颗粒、2.35:1 遮幅
- **声音**（`audio/`）：减法合成的 pad 与弦乐、共振峰合成的合唱、加法合成的钢琴、FM 钟声与八音盒、座头鲸的歌声（谐波滑音）、水滴、气泡（Minnaert 共振）、水花、风、海浪、低频轰鸣，卷积混响；穿越水面时整条总线被低通"闷住"。所有音效都对齐剪辑时间点

## 复现

```bash
cd sea-above   # 以下命令都在本目录运行
apt-get install -y libegl1 libegl-mesa0 libgl1-mesa-dri fonts-noto-cjk fonts-noto-cjk-extra
pip install -r requirements.txt

# 静帧 / 低分辨率动态预览
python render.py still s1_drop --t 3 14 22 --w 960 --spp 2
python render.py preview s4_above --w 480 --spp 1

# 完整流程：渲染、配乐、母版剪辑、两遍压缩网络版（需要 FFmpeg）
# 全分辨率 HDR 帧支持断点续渲，4 核 CPU 上约 6 小时
./make_film.sh
```

脚本先生成配乐 `out/score.wav`，再由 `edit.py` 输出高码率母版 `out/the_sea_above_master.mp4`。随后用 FFmpeg 的 libx264 两遍编码生成网络版 `out/the_sea_above.mp4`：视频目标码率约 9.2 Mb/s，AAC 音频 224 kb/s，并设置 `faststart` 以便网页播放。仓库保留的是网络版；母版与中间帧不提交。

已有 HDR 帧时，可单独重新制作配乐与母版：`python -m audio.score out/score.wav`，然后执行 `python edit.py --audio out/score.wav --out out/the_sea_above_master.mp4`。这一步尚未生成两遍压缩的网络版；完整网络编码命令见 `make_film.sh`。

第一次渲染时会把地形烘焙到 `cache/`。HDR 帧以对数编码的 16 位 PNG 存在 `cache/w1920/<镜头>/`，调色和剪辑可以在不重新渲染的情况下反复调整。

## 目录

```
engine/      渲染器（EGL + llvmpipe）、相机与样条、采样、散景景深、后期、地形烘焙、探针
shaders/     common（噪声、SDF、BRDF）· world_below / below_render（下方世界）· macro（草叶与露珠）
             · whale · underwater · world_above / above_render（上方世界）· shot1/3/4（每个镜头的入口）
shots/       每个镜头的时长、相机运动、动画参数和调色
audio/       synth.py（合成器）· score.py（配乐与音效的时间线）· analyze.py（频谱与响度检查）
render.py    渲染静帧 / 预览 / 全分辨率帧
edit.py      剪辑、叠化、片名、遮幅、混音输出
```
