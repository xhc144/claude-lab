# 费马平方和定理：一句话的证明，一架风车

面向**清华新领军数学英语面试**的一套数学讲解视频（中文版 + 英文版），配可编辑的 Manim 动画工程、中英对照讲稿和模拟面试问答手册。

> **定理（费马，1640）** 奇素数 p 能写成两个整数的平方和，当且仅当 p ≡ 1 (mod 4)。
>
> 证明采用扎吉尔 1990 年的“一句话证明”，并用**风车图**解释那个看似凭空出现的对合是怎么来的。

## 为什么选这个定理

| 面试追问 | 这个定理能讲出什么 |
| --- | --- |
| 陈述 | 一句话能说清，并可主动补充 p = 2、合数情形与唯一性 |
| 证明 | 一分钟讲完结构：集合 S、两个对合、奇偶性 |
| 必要条件 | 素性恰好用在两处（边界情形、不动点唯一），21 和 25 是现成反例；“模 4 余 1”只用在一处 |
| 为什么想到 | 风车图：同一个轮廓恰好两种切法，扎吉尔映射就是在两种切法之间切换 |
| 推广 | 合数（复数乘法）、高斯整数、x² + ny² 与类域论、拉格朗日四平方和 |
| 应用 | 勾股数的斜边、格点计数推出 π/4 = 1 − 1/3 + 1/5 − ⋯ |
| 个人思考 | “用奇偶性证明存在”，与握手引理、斯潘纳引理同源；存在性证明可以变成算法 |

它有足够的深度，又不冷门；证明短到能在白板上讲完，追问的空间却很大。与已做过的布劳维不动点定理、斯潘纳引理不重复，但能自然地联系到斯潘纳引理的奇偶路径论证。

## 工程结构

```
content/script.py   旁白唯一来源：中文旁白、英文逐句 + 中文释义、难词（音标 + 中文）、说话人
anim/geometry.py    风车几何（纯 Python，可单独运行自检）：集合 S、ζ、τ、轮廓、凹角、两种切法、路径
anim/base.py        NarratedScene：按旁白时长推进动画、记录字幕时间点；风车 Mobject、文字与卡片组件
anim/scenes_a.py    00–05 章        anim/scenes_b.py  06–08 章        anim/scenes_c.py  09–11 章
tts/synth.py        离线配音（sherpa-onnx：中文 MeloTTS，英文 Kokoro，英文默认 0.86 倍速）
tools/              subtitles.py（ASS/SRT + 词汇卡）· music.py（程序化背景音乐，人声处自动压低）
                    assemble.py（拼接、混音、烧录字幕）· make_docs.py（生成对照讲稿）· make_bg.py
build.sh            一键构建
```

**时间同步方式**：每句旁白都有 id。场景里写 `with self.say("w6"):`，动画就在这句话的时长内播放；`self.at(k)` 等到第 k 句开始再出下一个动作。时长来自配音清单 `build/audio/<lang>/manifest.json`，没有配音时按语速估算。场景渲染时把每句话的起始时间写进 `build/cues/`，字幕和配音都按这份记录放置，所以修改讲稿或换配音后重新构建即可，无需手动对轴。

## 构建

```bash
cd windmill-theorem
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
# 系统依赖（Ubuntu）：ffmpeg、texlive-latex-extra、dvisvgm、fonts-noto-cjk、libcairo2-dev、libpango1.0-dev，以及 Inter 字体

PY=.venv/bin/python MANIM=.venv/bin/manim bash build.sh zh preview   # 480p 预览，4 核约 10 分钟
PY=.venv/bin/python MANIM=.venv/bin/manim bash build.sh all          # 两个语言的 1080p 成片
```

单独渲染一章：`WT_LANG=en manim -ql anim/scenes_b.py S06_Windmill`。

### 加入配音

1. 获取 sherpa-onnx 的两个官方模型，放到 `models/`：
   - 中文：`vits-melo-tts-zh_en`（MeloTTS 中英混读）
   - 英文：`kokoro-en-v0_19`（或 `kokoro-multi-lang-v1_0`；旁白 am_michael、考官 bm_george、考生 af_sarah，可用 `--voices` 改）
2. 运行
   ```bash
   TTS_ZH=models/vits-melo-tts-zh_en TTS_EN=models/kokoro-en-v0_19 \
   PY=.venv/bin/python MANIM=.venv/bin/manim bash build.sh all
   ```
   英文默认 0.86 倍速，便于跟读；可用 `python tts/synth.py --lang en --model-dir ... --speed 0.9` 调整。

### 修改内容

- 改旁白：编辑 `content/script.py`，然后 `python tools/make_docs.py` 更新对照讲稿，再重新构建。`[[显示||朗读]]` 可以让字幕显示公式、配音读出文字。
- 改动画：编辑对应的 `anim/scenes_*.py`。屏幕文字用 `T("中文", "English")`，两个语言版本共用同一份动画代码。
- 校验数学：`python anim/geometry.py` 对若干素数检查 ζ 是对合、恰有一个不动点，以及 ζ 前后的风车轮廓完全相同。

## 数学校对

- 对 400 以内所有 p ≡ 1 (mod 4) 的素数验证：ζ 映 S 到 S、ζ∘ζ = id、唯一不动点为 (1, 1, (p−1)/4)；ζ 前后两架风车的单元格集合完全相同（第二种情形中旋转方向相反）。
- p = 41：|S| = 11，从 (1, 1, 10) 交替作用 τ、ζ 恰好走遍全部 11 个元素，终点 (5, 2, 2)，即 41 = 5² + 4²。
- 反例：21 的两个 ζ 不动点 (1, 1, 5)、(3, 3, 1)；25 的 (1, 3, 2) 落在边界 x = y − z 上。
- 史实：费马致梅森信件日期为 1640 年 12 月 25 日；欧拉的证明约完成于 1749 年；扎吉尔论文见 *Amer. Math. Monthly* 97 (1990), p. 144，浓缩自希思-布朗 1984 年的证明。
