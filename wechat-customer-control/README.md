# 微信客服控制台

双击桌面「微信客服控制台」打开。程序控制腾讯云 `tencent-ubuntu` 上的微信客服。

1. 打开后自动显示当前服务群和运行状态。
2. 在输入框填写微信里显示的完整群名，点击「切换服务群」。账号需要已经在这个群里。
3. 切换成功后，旧群停止服务，新群保持暂停。核对后点击「恢复回复」。
4. 点击「暂停回复」可停止客服，微信客户端继续在线；点击「刷新状态」查看当前状态。

切群只改变客服服务的目标，不执行退群或加群。新群第一次开始服务会沿用原程序的历史消息基线；切回使用过的群时保留该群的记忆和待处理任务，恢复后继续处理。待回复和待投递数量显示在窗口中。

请给不同群使用有区别的名称；当前微信界面接入按群名搜索，无法可靠区分重名群。找不到群或标题不匹配时，原服务名单保持不变，客服会保持暂停；核对群名后可重试。

程序使用本机已有的 SSH 密钥和主机别名，不保存登录密码或 AI API 密钥，也不新增公网管理端口。只读取运行状态与群标题，不提供发送消息功能。切换前会把配置和记忆库备份到服务器 `/home/ubuntu/wx-ai-assistant/deploy/desktop-control/`，备份不会下载到本机。

桌面快捷方式指向 `dist/WeChatCustomerControl.exe`，无需单独安装 Python。新版界面包含「概览」「最近群聊」「连接设置」三个页面。源码也可通过 `python app.py` 运行，需要 PySide6；`python app.py --smoke-test` 只检查离屏窗口，不连接服务器；`python app.py --preview` 只读服务器状态并保存预览截图。最近使用的群名和 SSH 别名保存在 `%LOCALAPPDATA%/WeChatCustomerControl/settings.json`。

重新打包：在 PowerShell 里运行 `./build.ps1`（需要 PyInstaller 和 PySide6）。

测试：`python -m unittest discover -s tests -v`。真实服务器验证仅执行状态读取，未替用户更换服务群。
